Paperback - версия 0.9.2

Введение

Paperback — это лёгкий, быстрый и доступный ридер электронных книг и документов для всех, от случайных читателей до опытных пользователей. Он разработан с учётом доступности для программ экранного доступа, высокой скорости работы и без излишних компонентов.

Системные требования

Paperback в настоящее время работает на Windows 10/11 и всех современных версиях ARM macOS. Нативные приложения для iOS и Android находятся в активной разработке, публичные тестовые версии планируются вскоре после выпуска версии 0.9.0 для настольных компьютеров, перед объединённым выпуском версии 1.0 для всех четырёх платформ.

Возможности

  • Полностью автономен, не требует установки дополнительного ПО на компьютер для начала чтения.
  • Невероятно быстр, даже на старом оборудовании.
  • Простой интерфейс с вкладками, позволяющий открывать несколько документов одновременно рядом друг с другом.
  • Сохраняет точную позицию чтения для каждого открытого документа.
  • При желании помнит, какие документы были открыты при закрытии программы, и восстанавливает их при следующем запуске.
  • Включает функции навигации, аналогичные режиму веб-просмотра многих программ экранного доступа, для быстрой и удобной навигации по документам.
  • Включает надёжный диалог поиска с такими функциями, как история и поддержка регулярных выражений.
  • Может работать полностью портативно или устанавливаться с автоматической настройкой ассоциаций файлов.
  • Поддерживает огромное количество распространённых форматов файлов.

Совместимость с программами экранного доступа

Paperback хорошо работает со всеми основными программами экранного доступа. Однако есть одна известная проблема для пользователей JAWS.

JAWS и дисплеи Брайля

Если вы используете JAWS с дисплеем Брайля, вы можете обнаружить, что длинные абзацы обрезаются при прокрутке вперёд с помощью клавиш навигации дисплея. Команда чтения текущего абзаца также затронута. Это ошибка в обработке JAWS текстового элемента управления RICHEDIT50W, а не в самом Paperback, и на исправление которой потребовалось довольно много времени, учитывая отношение Vispero к решению проблем с открытым исходным кодом.

Обходное решение, которое в конце концов появилось в группе обсуждений JAWS после месяцев ожидания, состоит в редактировании paperback.jcf и установке параметра “Braille Presentation and Panning” на “Always use DOM if available”. Вы также захотите включить “Pan Text by Paragraph”, иначе ваш дисплей останется на активном абзаце вместо продвижения. При включении обоих параметров прокрутка должна работать правильно.

Поддерживаемые типы файлов

Paperback поддерживает следующие форматы и расширения:

  • CHM справки (.chm)
  • DAISY книги (.opf, .zip)
  • EPUB книги (.epub)
  • FB2 электронные книги (.fb2)
  • HTML документы (.htm, .html, .xhtml)
  • Markdown документы (.md, .markdown, .mdx, .mdown, .mdwn, .mkd, .mkdn, .mkdown, .ronn)
  • Microsoft Word документы (.docx, .docm, .doc)
  • MOBI/Kindle книги (.mobi, .azw, .azw3)
  • OpenDocument презентации (.odp, .fodp)
  • OpenDocument текстовые файлы (.odt, .fodt)
  • PDF документы (.pdf)
  • PowerPoint презентации (.pptx, .pptm, .ppt)
  • RTF документы (.rtf)
  • Простые текстовые файлы и логи (.txt, .log)

Сочетания клавиш

Paperback разработан для использования с приоритетом на клавиатуру. Ниже приведены текущие сочетания клавиш.

Сочетания клавиш ниже предназначены для Windows. Если macOS отличается, эквивалент указан в скобках — в основном потому, что Ctrl+G, Ctrl+W и Alt+Left/Right уже зарезервированы другими системными соглашениями или соглашениями приложений на этой платформе.

Меню “Файл”

  • Ctrl+O: открыть документ.
  • Ctrl+F4 (macOS: Cmd+W): закрыть текущий документ.
  • Ctrl+Shift+F4 (macOS: Cmd+Shift+W): закрыть все открытые документы.
  • Ctrl+Shift+T: повторно открыть последний закрытый документ.
  • Ctrl+R: показать диалог “Все документы” (из “Последние документы”).
  • Ctrl+Q: выход (только Windows; на macOS это находится в меню приложения).

Меню “Перейти”

  • Ctrl+F: показать диалог поиска.
  • F3 (macOS: Cmd+G): найти далее.
  • Shift+F3 (macOS: Cmd+Shift+G): найти предыдущее.
  • Ctrl+G (macOS: Cmd+L): перейти к строке.
  • Ctrl+Shift+G (macOS: Cmd+Shift+L): перейти к проценту.
  • Ctrl+P: перейти на страницу (если поддерживается текущим документом).
  • =: объявить текущий процент прочитанного.
  • Alt+Left (macOS: Cmd+[): вернуться в истории навигации.
  • Alt+Right (macOS: Cmd+]): перейти вперёд в истории навигации.
  • [: предыдущий раздел.
  • ]: следующий раздел.
  • Shift+H: предыдущий заголовок.
  • H: следующий заголовок.
  • Shift+1–Shift+6: предыдущий заголовок уровня 1–6.
  • 1–6: следующий заголовок уровня 1–6.
  • Shift+P: предыдущая страница.
  • P: следующая страница.
  • Shift+B: предыдущая закладка.
  • B: следующая закладка.
  • /: установить временную закладку.
  • \: перейти к временной закладке.
  • Shift+N: предыдущая заметка.
  • N: следующая заметка.
  • Ctrl+B: перейти ко всем закладкам и заметкам.
  • Ctrl+Alt+B: перейти только к закладкам.
  • Ctrl+Alt+M: перейти только к заметкам.
  • Ctrl+Shift+W (macOS: RawCtrl+Shift+W, то есть физическая клавиша Control, а не Cmd): просмотреть текст заметки в текущей позиции.
  • Shift+K: предыдущая ссылка.
  • K: следующая ссылка.
  • Shift+G: предыдущее изображение.
  • G: следующее изображение.
  • Shift+F: предыдущая фигура.
  • F: следующая фигура.
  • Shift+T: предыдущая таблица.
  • T: следующая таблица.
  • Shift+S: предыдущий разделитель.
  • S: следующий разделитель.
  • Shift+L: предыдущий список.
  • L: следующий список.
  • Shift+I: предыдущий элемент списка.
  • I: следующий элемент списка.
  • Shift+,: перейти в начало текущего контейнера (списка или таблицы).
  • ,: перейти в конец текущего контейнера (списка или таблицы).

Меню “Инструменты”

  • Ctrl+W (macOS: RawCtrl+W, то есть физическая клавиша Control, а не Cmd): показать количество слов в текущем документе.
  • Ctrl+I: показать информацию о документе.
  • Ctrl+T: показать оглавление.
  • F7: показать список элементов.
  • Ctrl+Shift+C: открыть содержащую папку.
  • Ctrl+Shift+V: открыть текущее содержимое в Web View.
  • Ctrl+U: просмотреть исходный код документа в новой вкладке.
  • Ctrl+Shift+E: экспортировать данные документа (.paperback).
  • Ctrl+Shift+I: импортировать данные документа (.paperback).
  • Ctrl+E: экспортировать текущий документ в простой текст.
  • Ctrl+Shift+B: переключить закладку в текущей позиции выделения/курсора.
  • Ctrl+Shift+N: добавить или отредактировать заметку закладки в текущей позиции выделения/курсора.
  • Ctrl+Alt+W: переключить перенос слов.
  • Ctrl+Space: проиграть/пауза звукового повествования.
  • ': перемотать звуковое повествование вперёд.
  • ;: перемотать звуковое повествование назад.
  • Ctrl+': увеличить величину перемотки звука.
  • Ctrl+;: уменьшить величину перемотки звука.
  • F11 (macOS: RawCtrl+Ctrl+F, то есть Control+Command+F): переключить полноэкранный режим.
  • Ctrl+,: открыть параметры (macOS: “Параметры” в меню приложения).
  • Ctrl+Shift+S: переключить таймер сна.

Меню “Справка”

  • Ctrl+F1: показать диалог “О программе”.
  • F1: просмотреть справку в браузере по умолчанию.
  • Shift+F1: просмотреть справку в Paperback.
  • Ctrl+Shift+U: проверить обновления.
  • Ctrl+D: открыть страницу пожертвования в браузере по умолчанию.

Дополнительные клавиши просмотра документов

  • Delete / Numpad Delete на элементе управления вкладкой: закрыть выбранную вкладку документа.
  • Enter или Space в тексте документа: активировать ссылку в курсоре или открыть представление таблицы при наведении на маркер таблицы.
  • Shift+F10 или клавиша Menu/Application в тексте документа: открыть контекстное меню.

Журнал изменений

Версия 0.9.2

  • Аудиокниги больше не заставляют экранный диктор читать множество пробелов при фокусировке на текстовое поле.
  • Аудиокниги теперь называют файл по мере прохождения по секциям.
  • Аудиокниги теперь показывают реальную длительность вместо утверждения, что каждый файл длится 24 часа.
  • Закрытие веб-представления с помощью Escape больше не вызывает отладочное предупреждение после перехода по ссылке внутри него.
  • Копирование после выделения всего теперь дает вам весь документ вместо только загруженной части.
  • Find теперь сразу переходит к найденной строке вместо того, чтобы экранный диктор читал окно заново при возврате фокуса на книгу.
  • Исправлены EPUB-файлы, содержащие лишний блок ZIP64, которые отказывались открываться с ошибкой “Invalid local file header”.
  • Исправлены длинные документы, возвращающиеся в начало при непрерывном чтении экранным диктором.
  • Ссылки в WebView теперь переводят вас в нужную секцию вместо ошибки “File not found”.
  • Автоматическое объявление “Document reloaded” больше не прерывает экранный диктор на середине предложения, а ждет завершения высказывания.
  • Вкладка General диалога Settings теперь переключается по параметрам в том порядке, в котором они появляются на экране, с опцией канала обновления прямо после опции проверки обновлений.
  • Windows теперь всегда показывает “Paperback” в меню Open With вместо полного слогана программы.
  • Word Count и Document Info теперь показывают количество файлов в аудиокниге и общую продолжительность.

Версия 0.9.1

  • Звуки закладок и заметок теперь воспроизводятся на macOS.
  • DAISY-книги теперь воспроизводят аудио на macOS вместо открытия и отслеживания временной шкалы в тишине.
  • Исправлено исчезновение кудрявых кавычек, тире и подобных символов из документов RTF, соединяющих окружающие слова.
  • Исправлена утечка необработанных данных изображений RTF в документ в виде искаженного текста.
  • Исправлено сохранение устаревших записей в подменю “Recent Documents” до перестроения.
  • Клавиатурные ускорители вернулись во все переводы, поэтому меню русского языка снова имеют доступ с клавиатуры.
  • Большие документы CHM теперь открываются в семь раз быстрее.
  • Открытые документы теперь регистрируются в Windows, поэтому они появляются в списке перехода панели задач и недавнем списке меню “Пуск”.
  • Options переименован на Settings в соответствии с мобильными приложениями и на macOS с соглашением платформы.
  • Paperback теперь запоминает положение окна, размер и состояние развернутости между запусками.
  • Формы множественного числа теперь переводятся, поэтому сообщения, которые считают вещи, правильно читаются на языках, требующих более одной формы.
  • Выбор ncc.html DAISY-книги теперь открывает полную аудиокнигу вместо только текста.
  • Имена действий диалога Customize Keyboard Shortcuts теперь можно переводить.
  • Название документа теперь идет первым в строке заголовка, поэтому открытые книги можно различить на панели задач и в Alt+Tab.
  • Диалог обновления теперь переведен.

Версия 0.9.0

Добавлено

General

  • Инструмент CLI под названием pb для быстрого преобразования любого из поддерживаемых форматов Paperback в HTML, Markdown или простой текст.
  • Опция для перезагрузки документов, измененных другими программами на диске.
  • Опция View Source для открытия исходного кода документа в новой вкладке, полезно, например, для редактирования Markdown.
  • Текст документа теперь разбит на страницы, что означает, что вы можете загружать книги с десятками миллионов слов всего за пару секунд. Пожалуйста, сообщайте о найденных проблемах.

Platform Support

  • Поддержка ARM64 Windows!
  • Встроенная поддержка macOS!
  • Переключение полноэкранного режима.

All Documents Dialog

  • Кнопка для поиска отсутствующих книг, которые изменили свой путь.
  • Фильтр статуса и строка статуса для фильтрации по статусу документа и просмотра количества показанных и выбранных документов.
  • Ярлык Ctrl+Shift+A для отмены выделения всех документов.

Options and Readability

  • Вкладка читаемости со следующими опциями:
    • Word wrap (перемещено из general);
    • Render tables inline (новое в этом выпуске, см. ниже);
    • Font;
    • Background color;
    • Line spacing;
    • Paragraph spacing;
    • Letter spacing;
    • Text alignment.
  • Пункт меню word wrap и соответствующая клавиша быстрого доступа.
  • Переключатель для определения способа отображения таблиц и унифицированное отображение таблиц во всех документах.

Navigation

  • Поддержка навигации по контейнеру.
  • Опция автоматического перемещения курсора в начало строки при навигации между строками, аналогично режиму обзора в экранных дикторах.
  • Ярлык equals для объявления текущего процента прохождения документа.

Bookmarks

  • Временные закладки: вы можете иметь одну на документ, и они сохраняются. Используйте slash для установки и backslash для переходов.

Word Count

  • Приблизительное время чтения в диалоге подсчета слов, а также возможность установить скорость чтения, чтобы эта метрика была полезной.
  • Если активно выделение при открытии диалога подсчета слов, теперь будет показано количество выделенных слов.

Keyboard Shortcuts

  • Возможность настраивать каждый ярлык клавиатуры в приложении через простой диалог.
  • Настраиваемый ярлык клавиатуры для восстановления Paperback из системного трея.

Languages

  • Голландский, финский и польский.

Export

  • Расширен пункт меню export для экспорта в HTML и Markdown в дополнение к простому тексту.

Updater

  • Кнопка отмены в диалоге выполняющегося обновления.
  • Программа обновления теперь проверяет, не был ли загруженный файл подделан.

Web View

  • Веб-представление теперь открывается в текущей позиции чтения.

DAISY Books

  • Поддержка DAISY 2.0 книг.
  • Поддержка воспроизведения DAISY 2.02 аудио.

Audio Books

  • Возможность воспроизведения аудиокниг с поддержкой DAISY audio (включая DAISY audio + text) и zip-архивов аудиофайлов.
  • Ярлыки клавиатуры и пункты меню для воспроизведения/паузы повествования, поиска вперед и назад, а также регулировки величины поиска.
  • Опции синхронизации каретки чтения с воспроизведением аудио, установки величины поиска аудио и выбора продолжения поиска в следующую главу при переходе в конец.

CHM Documents

  • Поддержка списков, элементов списков, фигур и изображений.

PowerPoint

  • Документы PowerPoint теперь поддерживают таблицы.

Исправлено

General

  • Документы в устаревших кодировках CJK, таких как GBK, Big5 и Shift_JIS, теперь правильно отображаются вместо множества нечитаемых символов.
  • “Reopen last closed” попытка переоткрыть встроенный readme.
  • Выбранная вкладка не получила надлежащий фокус после перезагрузки Paperback.
  • Обработка Paperback файлов на сетевых дисках Windows: нажатие “show file in folder” теперь правильно фокусирует файл в сетевом хранилище, и пути больше не содержат странные символы.
  • Файлы .paperback больше не будут принудительно загружаться при восстановлении документов; вместо этого вам будет предложено подтверждение при обнаружении.
  • Open containing folder теперь фокусирует указанный файл в explorer.
  • Открытие readme теперь соответствует выбранному языку.
  • Пользовательский интерфейс Paperback теперь правильно масштабируется на дисплеях с высоким DPI.
  • Меню теперь правильно обновляется и фокус переходит на текстовый элемент управления при открытии справки в Paperback.
  • Перешли на гораздо более безопасный метод IPC на Windows.
  • Название активного документа теперь будет прочитано при переключении между вкладками.
  • Сокращено использование памяти на больших документах путем уменьшения размера таблиц индексации в два раза.

All Documents Dialog

  • Escape не закрывает диалоги Document Info и All Documents.
  • Строка заголовка не обновляется после закрытия документа из диалога all documents.
  • Readme.html больше не добавляется в список all documents при открытии через Shift+F1.
  • Удаление документов из диалога recents теперь также закрывает их активную вкладку.
  • Фильтр поиска теперь сохраняется после удаления документа.

Navigation

  • Page navigation объявляющая неправильный текст строки в некоторых ситуациях.
  • Go to Line, Go to Page и Go to Percent размещение курсора в неправильной позиции в больших документах.
  • Find и Find Next не соблюдающие окно загруженного документа в больших документах.

Bookmarks

  • Звуки закладок/заметок теперь должны правильно воспроизводиться исключительно при навигации над словом, содержащим такой звук.

Readability

  • Применение word wrap отправляющее вас в начало документа.

Web View

  • Диалог webview не был изменяемым размером и открывался в очень маленьком начальном размере.
  • Изображения теперь должны правильно отображаться во встроенном webview.

Updater

  • Программа обновления теперь правильно показывает содержимое тегов markdown code в примечаниях к выпуску.

DAISY Books

  • DAISY книги показывающие неправильную информацию в строке статуса.
  • Загрузка DAISY книг с поддельными объявлениями кодировки.

RTF Documents

  • Парсинг документов RTF с нелатинскими символами.
  • RTF группы \pict для того, чтобы встроенные данные изображений больше не попадали в текст документа.

Mobi/AZW3 Books

  • Якоря filepos в книгах Mobi разбивающие HTML-теги и помещающие мусор в текст книги.
  • Ссылки в старых книгах Mobi.
  • Значительно улучшен парсинг AZW3.

Word Documents

  • Документы Word со специфичными для локали именами стилей не отображающие надлежащим образом их заголовки.

HTML/XHTML Documents

  • Элементы dl, dt и dd не производящие разрывы строк в документах XHTML.

PDF Documents

  • Paperback теперь возвращается к простому извлечению текста для неправильно помеченных PDF.
  • PDF-документы содержащие управляющие символы в названии и/или закладках больше не будут вызывать сбой Paperback при открытии.
