Paperback - версия 0.9.2

Введение

Paperback — это легкая, быстрая и доступная программа для чтения электронных книг и документов для всех, от случайных читателей до опытных пользователей. Она разработана с учетом совместимости с программами экранного доступа, высокой скорости работы и отсутствия лишних функций.

Системные требования

Paperback в настоящее время работает на Windows 10/11 и всех современных версиях ARM macOS. Нативные приложения для iOS и Android находятся в активной разработке, с публичными тестовыми сборками, запланированными вскоре после выпуска версии 0.9.0 для настольных компьютеров, перед единым выпуском версии 1.0, охватывающим все четыре платформы.

Особенности

  • Полностью автономное приложение, не требующее установки дополнительного ПО на ваш компьютер для начала чтения.
  • Невероятно быстрое, даже на старом оборудовании.
  • Простой интерфейс с вкладками, позволяющий открывать столько документов, сколько вам нужно, рядом друг с другом.
  • Сохраняет вашу точную позицию чтения для каждого открытого документа.
  • Может запомнить, какие документы были открыты при закрытии программы, и восстановить их при следующем запуске.
  • Включает функции навигации, похожие на те, которые встречаются в режиме веб-поиска многих программ экранного доступа, для быстрой и удобной навигации по документам.
  • Включает надежный диалог поиска с функциями, такими как история и поддержка регулярных выражений.
  • Может работать полностью портативно или быть установлена с автоматической настройкой связей между файлами и приложением.
  • Поддерживает огромный набор распространенных форматов файлов.

Совместимость с программами экранного доступа

Paperback хорошо работает со всеми основными программами экранного доступа. Однако есть одна известная проблема для пользователей JAWS.

JAWS и дисплеи Брайля

Если вы используете JAWS с дисплеем Брайля, вы можете обнаружить, что длинные абзацы усекаются при перелистывании вперед с помощью клавиш навигации вашего дисплея. Команда чтения текущего абзаца также затронута. Это ошибка в обработке JAWS текстового элемента управления RICHEDIT50W, а не что-то в самом Paperback, и ошибка, для исправления которой потребовалось немало времени, учитывая энтузиазм Vispero к реагированию на проблемы с открытым исходным кодом.

Обходной путь, в конце концов выявленный через группу обсуждения JAWS после месяцев ожидания, заключается в редактировании paperback.jcf и установке параметра «Braille Presentation and Panning» на «Always use DOM if available». Вы также захотите включить «Pan Text by Paragraph», иначе ваш дисплей будет оставаться на активном абзаце вместо продвижения вперед. При обоих включенных параметрах перелистывание должно работать правильно.

Поддерживаемые форматы файлов

Paperback поддерживает следующие форматы и расширения:

  • Архивы комиксов (.cbz)
  • CHM файлы справки (.chm)
  • DAISY книги (.opf, .zip)
  • EPUB книги (.epub)
  • FB2 электронные книги (.fb2)
  • HTML документы (.htm, .html, .xhtml)
  • Справочные страницы, как man, так и BSD mdoc (.1 по .9, .man, .roff и сжатые версии каждого)
  • Markdown документы (.md, .markdown, .mdx, .mdown, .mdwn, .mkd, .mkdn, .mkdown, .ronn)
  • Документы Microsoft Word (.docx, .docm, .doc)
  • M4B аудиокниги (.m4b)
  • MOBI/Kindle книги (.mobi, .azw, .azw3)
  • OpenDocument презентации (.odp, .fodp)
  • OpenDocument текстовые файлы (.odt, .fodt)
  • PDF документы (.pdf)
  • PowerPoint презентации (.pptx, .pptm, .ppt)
  • RTF документы (.rtf)
  • WinHelp файлы (.hlp)
  • Простые текстовые файлы и логи (.txt, .log)

Сочетания клавиш

Paperback разработан для использования с приоритетом на клавиатуру. Вот текущие сочетания клавиш.

Сочетания ниже предназначены для Windows. Если macOS отличается, эквивалент указан в скобках — в основном потому, что Ctrl+G, Ctrl+W и Alt+Left/Right уже зарезервированы другими системными соглашениями или соглашениями приложений на этой платформе.

Меню «Файл»

  • Ctrl+O: открыть документ.
  • Ctrl+F4 (macOS: Cmd+W): закрыть текущий документ.
  • Ctrl+Shift+F4 (macOS: Cmd+Shift+W): закрыть все открытые документы.
  • Ctrl+Shift+T: повторно открыть последний закрытый документ.
  • Ctrl+R: показать диалог «Все документы» (из раздела «Последние документы»).
  • Ctrl+Q: выход (только Windows; на macOS это находится в меню приложения).

Меню «Переход»

  • Ctrl+F: показать диалог поиска.
  • F3 (macOS: Cmd+G): найти далее.
  • Shift+F3 (macOS: Cmd+Shift+G): найти назад.
  • Ctrl+G (macOS: Cmd+L): перейти к строке.
  • Ctrl+Shift+G (macOS: Cmd+Shift+L): перейти к проценту.
  • Ctrl+P: перейти к странице (если поддерживается текущим документом).
  • =: объявить текущий процент прочтения и страницу, например «15%, страница 30». Страница опускается для документов без номеров страниц.
  • Alt+Left (macOS: Cmd+[): вернуться в истории навигации.
  • Alt+Right (macOS: Cmd+]): перейти вперед в истории навигации.
  • [: предыдущий раздел.
  • ]: следующий раздел.
  • Shift+H: предыдущий заголовок.
  • H: следующий заголовок.
  • Shift+1 по Shift+6: предыдущий заголовок уровня 1–6.
  • 1 по 6: следующий заголовок уровня 1–6.
  • Shift+P: предыдущая страница.
  • P: следующая страница.
  • Shift+B: предыдущая закладка.
  • B: следующая закладка.
  • /: установить временную закладку.
  • \: перейти к временной закладке.
  • Shift+N: предыдущая заметка.
  • N: следующая заметка.
  • Ctrl+B: перейти ко всем закладкам и заметкам.
  • Ctrl+Alt+B: перейти к закладкам только.
  • Ctrl+Alt+M: перейти к заметкам только.
  • Ctrl+Shift+W (macOS: RawCtrl+Shift+W, то есть физическая клавиша Control вместо Cmd): просмотреть текст заметки в текущей позиции.
  • Shift+K: предыдущая ссылка.
  • K: следующая ссылка.
  • Shift+G: предыдущее изображение.
  • G: следующее изображение.
  • Shift+F: предыдущий рисунок.
  • F: следующий рисунок.
  • Shift+T: предыдущая таблица.
  • T: следующая таблица.
  • Shift+M: предыдущая формула.
  • M: следующая формула.
  • Shift+S: предыдущий разделитель.
  • S: следующий разделитель.
  • Shift+L: предыдущий список.
  • L: следующий список.
  • Shift+I: предыдущий элемент списка.
  • I: следующий элемент списка.
  • Shift+,: перейти к началу текущего контейнера (список или таблица).
  • ,: перейти после конца текущего контейнера (список или таблица).

Меню «Инструменты»

  • Ctrl+W (macOS: RawCtrl+W, то есть физическая клавиша Control вместо Cmd): показать количество слов в текущем документе.
  • Ctrl+I: показать информацию о документе.
  • Ctrl+T: показать оглавление.
  • F7: показать список элементов.
  • Ctrl+Shift+C: открыть содержащую папку.
  • Ctrl+Shift+V: открыть текущее содержимое в веб-представлении.
  • Ctrl+U: просмотреть исходный код документа в новой вкладке.
  • Ctrl+Shift+E: экспортировать данные документа (.paperback).
  • Ctrl+Shift+I: импортировать данные документа (.paperback).
  • Ctrl+E: экспортировать текущий документ в простой текст.
  • Ctrl+Shift+B: переключить закладку в текущем выделении/позиции курсора.
  • Ctrl+Shift+N: добавить или изменить заметку закладки в текущем выделении/позиции курсора.
  • Ctrl+Alt+W: переключить перенос слов.
  • Ctrl+Space: воспроизвести/пауза аудионарратора.
  • ': перемотка аудионарратора вперед.
  • ;: перемотка аудионарратора назад.
  • Ctrl+': увеличить размер перемотки аудио.
  • Ctrl+;: уменьшить размер перемотки аудио.
  • F11 (macOS: RawCtrl+Ctrl+F, то есть Control+Command+F): переключить полноэкранный режим.
  • Ctrl+,: открыть параметры (macOS: «Параметры» в меню приложения).
  • Ctrl+Shift+S: переключить таймер сна.
  • Alt+F9 (macOS: Cmd+F9): отметить начало выделения, чтобы все от сюда до того, куда вы перейдете, можно было скопировать за один раз.
  • Alt+F10 (macOS: Cmd+F10): скопировать все от отмеченного начала выделения до текущей позиции.
  • Alt+Shift+F9 (macOS: Cmd+Shift+F9): вернуться к отмеченному началу выделения, оставив отметку на месте.

Меню «Справка»

  • Ctrl+F1: показать диалог «О программе».
  • F1: просмотреть справку в браузере по умолчанию.
  • Shift+F1: просмотреть справку в Paperback.
  • Ctrl+Shift+U: проверить обновления.
  • Ctrl+D: открыть страницу пожертвований в браузере по умолчанию.

Дополнительные клавиши для представления документа

  • Delete / Numpad Delete на элементе управления вкладкой: закрыть выбранную вкладку документа.
  • Enter или Space в тексте документа: перейти по ссылке или открыть представление таблицы или формулы в позиции курсора.
  • Shift+F10 или клавиша Menu/Application в тексте документа: открыть контекстное меню.

Журнал изменений

Версия 0.9.2

  • Аудиокниги больше не заставляют экранный диктор читать непрерывный ряд пробелов при фокусировке текстового поля.
  • Аудиокниги теперь озвучивают имя файла при переходе по разделам.
  • Аудиокниги теперь правильно сообщают реальную длительность вместо того, чтобы указывать 24 часа для каждого файла.
  • Закрытие Web View с помощью Escape больше не вызывает окно отладки после перехода по ссылке внутри него.
  • Копирование после Выделить всё теперь дает весь документ вместо только загруженной части.
  • Функция поиска теперь сразу переходит на найденную строку, вместо того чтобы ждать, пока экранный диктор перечитает окно при возврате фокуса в книгу.
  • Исправлены EPUB файлы с посторонним ZIP64 блоком, отказывающиеся открываться с ошибкой “Invalid local file header”.
  • Исправлена проблема, при которой длинные документы возвращались в начало при непрерывном чтении экранным диктором.
  • Ссылки в WebView теперь открывают нужный раздел, вместо ошибки “File not found”.
  • Обозначьте начало выделения с помощью Alt+F9, скопируйте всё от начала до текущей позиции с помощью Alt+F10 и вернитесь к отметке с помощью Alt+Shift+F9 для копирования большого фрагмента текста без использования Shift+стрелки. Все три команды находятся в меню Сервис > Выделение и копирование.
  • Ярлык = теперь объявляет страницу в дополнение к процентам, например “15%, страница 30”, и остается прежним для документов без номеров страниц.
  • Автоматическое объявление “Документ перезагружен” больше не прерывает экранный диктор посередине предложения, а ждет, пока он закончит.
  • На вкладке General диалога Settings теперь правильная навигация по вариантам в порядке их отображения на экране, с опцией канала обновления прямо после опции проверки обновлений.
  • При обновлении переинициализированное окно теперь выводится на передний план вместо того, чтобы оставаться за другими окнами в Alt+Tab.
  • Windows теперь всегда показывает “Paperback” в меню “Открыть с помощью”, вместо полного описания программы.
  • Word Count и Document Info теперь показывают, сколько файлов содержит аудиокнига и её общую длительность.

Версия 0.9.1

  • Звуки закладок и примечаний теперь воспроизводятся на macOS.
  • DAISY книги теперь проигрывают аудио на macOS вместо открытия и отслеживания временной шкалы в тишине.
  • Исправлена проблема с исчезновением фигурных кавычек, эм-дашей и аналогичных символов из RTF документов, что приводило к слиянию окружающих слов.
  • Исправлена утечка сырых данных картинок RTF в документ в виде искаженного текста.
  • Исправлена проблема с сохранением устаревших записей в подменю “Последние документы” до их перестроения чем-то другим.
  • Клавиатурные акселераторы вернулись в каждый перевод, так что русское меню снова имеет доступ по клавиатуре.
  • Большие CHM документы теперь открываются в семь раз быстрее.
  • Открытые документы теперь регистрируются в Windows, поэтому они появляются в списке переходов панели задач и в списке недавних файлов в меню “Пуск”.
  • Options переименован в Settings в соответствии с мобильными приложениями и, на macOS, с соглашениями платформы.
  • Paperback теперь запоминает положение окна, размер и состояние максимизации между запусками.
  • Формы множественного числа теперь переведены, поэтому сообщения, считающие объекты, правильно читаются на языках, требующих более одной формы.
  • Выбор файла ncc.html книги DAISY теперь открывает полную аудиокнигу вместо только текста.
  • Имена действий в диалоге “Customize Keyboard Shortcuts” теперь можно переводить.
  • Заголовок документа теперь идет первым в строке заголовка, поэтому открытые книги можно различить в панели задач и Alt+Tab.
  • Диалог обновления теперь переведен.

Версия 0.9.0

Добавлено

Основное

  • Инструмент командной строки pb для быстрого преобразования любого поддерживаемого Paperback формата в HTML, Markdown или простой текст.
  • Опция для перезагрузки документов, измененных другими программами на диске.
  • Опция View Source для открытия исходного кода документа на новой вкладке, полезна для редактирования Markdown, например.
  • Текст документа теперь разбивается на страницы, что означает, что вы можете загружать книги с десятками миллионов слов всего за пару секунд. Пожалуйста, сообщайте об любых обнаруженных странностях.

Поддержка платформ

  • Поддержка ARM64 Windows!
  • Нативная поддержка macOS!
  • Переключение полноэкранного режима.

Диалог “Все документы”

  • Кнопка поиска для поиска пропавших книг, которые изменили свой путь.
  • Фильтр статуса и строка состояния для фильтрации по статусу документа и просмотра количества показанных и выбранных документов.
  • Ярлык Ctrl+Shift+A для отмены выделения всех документов.

Опции и читаемость

  • Вкладка читаемости со следующими опциями:
    • Перенос слов (перемещено из общих);
    • Визуализация таблиц встроенным образом (новое в этом выпуске, см. ниже);
    • Шрифт;
    • Цвет фона;
    • Расстояние между строками;
    • Расстояние между абзацами;
