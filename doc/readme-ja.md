# ペーパーバック - バージョン 0.8.5 {#paperback---version-0.8.5}

## はじめに {#introduction}

Paperbackは、カジュアルな読者からヘビーユーザーまで、あらゆるユーザー向けの、軽量で高速、かつアクセシビリティに優れた電子書籍・ドキュメント
リーダーです。スクリーンリーダーでの利用を想定したアクセシビリティ、高速な動作、そして余計な機能が一切ない
シンプルな使用感を追求して設計されています。

## 動作環境 {#system-requirements}

Paperbackは現在、Windows、macOS、iOS、Androidで動作します。

## 機能 {#features}

-   完全にスタンドアロン型で、読書を始めるために
    コンピュータにソフトウェアをインストールする必要はありません。
-   古いハードウェアでも驚くほど高速に動作します。
-   シンプルなタブ式インターフェースにより、
    好きなだけ多くの文書を並べて開くことができます。
-   開いているすべてのドキュメントにおいて、正確な読み進め位置を
    保存します。
-   オプションで、プログラムを終了した際に開いていた文書を記憶し、
    次回の起動時にそれらを復元します。
-   多くのスクリーンリーダーのウェブ
    閲覧モードに見られるようなナビゲーション機能を搭載しており、文書内を
    迅速かつ簡単に移動できます。
-   履歴や正規表現のサポートなどの機能を備えた、
    堅牢な検索ダイアログを搭載しています。
-   完全にポータブルで実行できるほか、ファイルの関連付けが
    自動的に設定されるようにインストールすることも可能です。
-   一般的なファイル形式を幅広くサポートしています。

## スクリーンリーダーとの互換性 {#screen-reader-compatibility}

Paperbackは、すべての主要なスクリーンリーダーで正常に動作します。ただし、
JAWSユーザーに関しては、1つの既知の問題があります。

### JAWSと点字ディスプレイ {#jaws-and-braille-displays}

JAWSを点字ディスプレイと併用している場合、ディスプレイの
ナビゲーションキーで前方にスクロールすると、長い
段落が切り捨てられてしまうことがあります。「現在の段落を読み上げる」コマンドも同様に影響を受けます。
これは、Paperback自体に起因するものではなく、JAWSによるRICHEDIT50Wテキストコントロールの処理におけるバグであり、
Vispero社がオープンソースソフトウェアの問題への対応に熱心であるにもかかわらず、
修正が明らかになるまでにかなりの時間を要しました。

数ヶ月の待ち時間を経て、最終的にJAWSのディスカッショングループを通じて
明らかになった回避策は、 `paperback.jcf` 「点字表示とパン」を
「利用可能な場合は常にDOMを使用」に設定することです。
また、「段落単位でテキストをパンする」を有効にする必要があります。そうしないと、
ディスプレイがアクティブな段落にとどまり、先へ進まなくなります。
両方の設定を適用すれば、パン操作は正しく機能するはずです。

## 現在サポートされているファイル 形式 {#currently-supported-file-types}

Paperbackは以下の形式および拡張子をサポートしています：

-   CHMヘルプファイル（`.chm`)
-   DAISYブック（`.opf`, `.zip`)
-   EPUB書籍 (`.epub`)
-   FB2形式の電子書籍 (`.fb2`)
-   HTMLドキュメント (`.htm`, `.html`, `.xhtml`)
-   Markdown文書 (`.md`, `.markdown`, `.mdx`, `.mdown`, `.mdwn`, `.mkd`,
    `.mkdn`, `.mkdown`, `.ronn`)
-   Microsoft Word文書 (`.docx`, `.docm`, `.doc`)
-   MOBI/Kindle書籍 (`.mobi`, `.azw`, `.azw3`)
-   OpenDocument形式のプレゼンテーション (`.odp`, `.fodp`)
-   OpenDocumentテキストファイル (`.odt`, `.fodt`)
-   PDF文書 (`.pdf`)
-   PowerPointプレゼンテーション (`.pptx`, `.pptm`, `.ppt`)
-   RTF文書 (`.rtf`)
-   プレーンテキストおよびログファイル (`.txt`, `.log`)

## キーボードショートカット {#keyboard-shortcuts}

Paperbackは、キーボードを主体とした操作を想定して設計されています。以下に現在の
ショートカットを記載します。

以下のショートカットは Windows 用です。macOS で異なる場合は、
括弧内に同等の操作が記載されています。これは主に、Ctrl+G、Ctrl+W、および
Alt+左/右が、そのプラットフォーム上の他のシステムやアプリの
慣例ですでに使用されているためです。

### 「ファイル」メニュー {#file-menu}

-   `Ctrl+O`: ドキュメントを開きます。
-   `Ctrl+F4` (macOS: `Cmd+W`): 現在の ドキュメントを閉じます。
-   `Ctrl+Shift+F4` (macOS: `Cmd+Shift+W`): 開いている
    すべてのドキュメントを閉じる。
-   `Ctrl+Shift+T`: 最後に閉じたドキュメントを再度開く。
-   `Ctrl+R`: 「すべてのドキュメント」ダイアログを表示します（「最近
    開いたドキュメント」から）。
-   `Ctrl+Q`: 終了（Windowsのみ。macOSでは、これは
    アプリメニュー内にあります）。

### 「移動」メニュー {#go-menu}

-   `Ctrl+F`: 「検索」ダイアログを表示します。
-   `F3` (macOS: `Cmd+G`): 次の検索。
-   `Shift+F3` (macOS: `Cmd+Shift+G`): 前の項目を 検索。
-   `Ctrl+G` (macOS: `Cmd+L`): 行へ移動。
-   `Ctrl+Shift+G` (macOS: `Cmd+Shift+L`): パーセントの位置へ 移動。
-   `Ctrl+P`: ページへ移動（現在の
    ドキュメントでサポートされている場合）。
-   `Alt+Left` (macOS: `Cmd+[`): ナビゲーション履歴を 1つ戻る。
-   `Alt+Right` (macOS: `Cmd+]`): ナビゲーション履歴を 前へ進む。
-   `[`: 前のセクション。
-   `]`: 次のセクション。
-   `Shift+H`: 前の見出し。
-   `H`: 次の見出し。
-   `Shift+1` から `Shift+6`: 前の見出し （レベル1～6）。
-   `1` ～まで: レベル `6`: レベル 1～6の次の見出し。
-   `Shift+P`: 前のページ。
-   `P`: 次のページ。
-   `Shift+B`: 前のしおり。
-   `B`: 次のしおり。
-   `Shift+N`: 前のメモ。
-   `N`: 次のメモ。
-   `Ctrl+B`: すべてのブックマークとメモへ移動。
-   `Ctrl+Alt+B`: ブックマークのみに移動。
-   `Ctrl+Alt+M`: メモのみに移動。
-   `Ctrl+Shift+W` (macOS: `RawCtrl+Shift+W`,
    つまり、Cmdキーではなく物理的なControlキー): 現在の位置にある
    メモの本文を表示します。
-   `Shift+K`: 前のリンク。
-   `K`: 次のリンク。
-   `Shift+G`: 前の画像。
-   `G`: 次の画像。
-   `Shift+F`: 前の図。
-   `F`: 次の図。
-   `Shift+T`: 前の表。
-   `T`: 次の表。
-   `Shift+S`: 前の区切り記号。
-   `S`: 次の区切り記号。
-   `Shift+L`: 前のリスト。
-   `L`: 次のリスト。
-   `Shift+I`: 前のリスト項目。
-   `I`: 次のリスト項目。
-   `Shift+,`: 現在のコンテナ（リスト
    またはテーブル）の先頭へ移動します。
-   `,`: 現在のコンテナ（リストまたは
    テーブル）の末尾を過ぎて移動します。

### 「ツール」メニュー {#tools-menu}

-   `Ctrl+W` （macOS： `RawCtrl+W`、つまり Cmd キーではなく物理的な
    Control キー）：現在の 文書の単語数を表示します。
-   `Ctrl+I`: ドキュメント情報を表示します。
-   `Ctrl+T`: 目次を表示します。
-   `F7`: 要素リストを表示します。
-   `Ctrl+Shift+C`: 親フォルダを開く。
-   `Ctrl+Shift+V`: 現在のコンテンツをWebビューで開く。
-   `Ctrl+U`: 新しいタブでドキュメントのソースを表示します。
-   `Ctrl+Shift+E`: ドキュメントデータをエクスポート (`.paperback`).
-   `Ctrl+Shift+I`: ドキュメントデータをインポート (`.paperback`).
-   `Ctrl+E`: 現在のドキュメントをプレーンテキストとしてエクスポート。
-   `Ctrl+Shift+B`: 現在の
    選択範囲／カーソル位置にブックマークを設定／解除します。
-   `Ctrl+Shift+N`: 現在の
    選択範囲／カーソル位置にブックマークのメモを追加または編集します。
-   `Ctrl+Alt+W`: 行の折り返しを切り替えます。
-   `Ctrl+,`: オプションを開く（macOS：アプリメニューの「環境設定」 ）。
-   `Ctrl+Shift+S`: スリープタイマーのオン／オフを切り替えます。

### 「ヘルプ」メニュー {#help-menu}

-   `Ctrl+F1`: 「バージョン情報」ダイアログを表示します。
-   `F1`: デフォルトのブラウザでヘルプを表示します。
-   `Shift+F1`: Paperback でヘルプを表示します。
-   `Ctrl+Shift+U`: 更新を確認します。
-   `Ctrl+D`: デフォルトの ブラウザで寄付ページを開きます。

### ドキュメント表示用の 追加キー {#additional-document-view-keys}

-   `Delete` / `Numpad Delete` : 選択したドキュメントタブを閉じます。
-   `Enter` または `Space` ドキュメントのテキスト内：
    カーソル位置のリンクを有効にするか、テーブル
    マーカー上にある場合はテーブルビューを開きます。
-   `Shift+F10` または、ドキュメント
    テキスト内の「メニュー／アプリケーション」キー：コンテキストメニューを開きます。

    目次に関する問題を修正しました。
-   マルチバイトの Unicode 文字を含む HTML
    ドキュメントでの見出しナビゲーションを修正しました。
-   wxWidgets のリグレッションにより、タイトルが長い文書で CPU
    使用率が高くなる問題を修正しました。
-   UTF-8 テキストファイルの読み込みを修正しました。
-   EPUB書籍のネストされた目次項目で、カーソルが
    誤った位置に配置される問題を修正しました。
-   特定の状況でアプリケーション終了時にクラッシュする問題を修正しました。
-   オプションダイアログに、ワードラップを有効または無効にするための
    チェックボックスを追加しました！
-   Paperbackの開発への寄付が可能になりました。
    ヘルプメニューの新しい「寄付」項目、またはGitHubリポジトリのメインページ下部にある
    「このプロジェクトをスポンサーする」リンクから寄付できます。
-   Markdown ドキュメントには常にタイトルが付くようになり、Paperback は
    事実上あらゆる Markdown ファイルを読み込めるようになりました。
-   PDFドキュメントには、メタデータが
    欠落している場合でも、常にタイトルが付くようになりました。
-   PDFライブラリをChromiumで使用されているものに切り替え、
    全体を通じてPDFの解析がはるかに信頼性の高いものになりました。
-   Paperbackは、一度に1つのインスタンスのみ実行できるようになりました。
    すでにPaperbackが実行中の状態で、ファイル名を指定してpaperback.exeを実行すると、
    そのドキュメントは既に実行中のインスタンスで開かれます。
-   タブコントロール内のドキュメントで Delete キーを押すと、
    そのドキュメントを閉じられるようになりました。

### バージョン 0.2.1 {#version-0.2.1}

-   「ページへ移動」ダイアログのページラベルに、総ページ数を
    追加しました。
-   ドキュメントの内容から、開いているドキュメントのリストへ
    タブキーで移動できるようになりました。
-   見出しのキー操作により、最近使用したドキュメントが
    十分に存在する場合に、それらが開いてしまうことがある問題を修正しました。
-   Paperback は、テキスト出力から不要なソフトハイフンを
    削除するようになりました。
-   見出しナビゲーションにより、誤った
    文字位置に移動してしまうことがある問題を修正しました。

### バージョン 0.2.0 {#version-0.2.0}

-   Markdown ドキュメントのサポートを追加しました！
-   PDF ドキュメントのサポートを追加しました。これには、ページ間の
    移動機能も含まれます！
-   epub 書籍や Markdown 文書を含む HTML コンテンツ内で、見出しを
    基準にナビゲートするためのキー操作を追加しました。これらのキー操作は、
    スクリーンリーダーと同様に機能するように設計されています。
-   マニフェストにURLエンコードされたファイル名を含むepubの
    読み込みを修正しました。
-   XHTMLが埋め込まれたEPUB 3書籍の読み込みに関する問題を修正しました。
-   ドキュメントが目次やセクションに対応していない場合、
    メニュー項目が無効化されるのではなく、音声でメッセージが読み上げられるようになりました。
-   「最近開いたドキュメント」メニューを追加しました！現在、直近に
    開いた10件のドキュメントが保存されており、そのうちの1つで
    Enterキーを押すと、そのドキュメントが開いて
    閲覧できるようになります。
-   「検索」ダイアログを完全に書き直し、操作性を大幅に簡素化するとともに、
    直近25件の検索履歴と正規表現の サポートを追加しました！
-   以前に開いたドキュメントは、アプリケーションの
    再起動後も記憶されるようになりました。これは、ツール
    メニューの新しいオプション項目から設定可能です。
-   Shift+F1キーを押すと、Paperback内で直接Readmeを開くことができるようになりました。
