# Paperback - версия 0.9.1

## Введение

Paperback — это лёгкое, быстрое и доступное приложение для чтения электронных книг и документов для всех, от обычных читателей до опытных пользователей. Оно разработано с учётом доступности для программ чтения с экрана, высокой скорости работы и отсутствия лишнего функционала.

## Системные требования

Paperback в настоящее время работает на Windows 10/11 и всех современных версиях ARM macOS. Нативные приложения для iOS и Android находятся в активной разработке, публичные тестовые сборки запланированы вскоре после выпуска версии 0.9.0 для настольных систем, перед единым выпуском версии 1.0 для всех четырёх платформ.

## Возможности

* Полностью автономное приложение, не требующее установки дополнительного ПО на ваш компьютер для начала чтения.
* Невероятно быстрое, даже на старом оборудовании.
* Простой интерфейс с вкладками, позволяющий открывать множество документов рядом.
* Сохраняет вашу точную позицию чтения для каждого открытого документа.
* При желании запоминает, какие документы были открыты при закрытии программы, и восстанавливает их при следующем запуске.
* Включает функциональность навигации, аналогичную режиму веб-просмотра во многих программах чтения с экрана, для быстрой и удобной навигации по документам.
* Включает надёжный диалог поиска с такими функциями, как история и поддержка регулярных выражений.
* Может работать полностью портативно или быть установлено с автоматической настройкой ассоциаций файлов.
* Поддерживает большой набор распространённых форматов файлов.

## Совместимость с программами чтения с экрана

Paperback хорошо работает со всеми основными программами чтения с экрана. Однако у пользователей JAWS есть одна известная проблема.

### JAWS и дисплеи Брайля

Если вы используете JAWS с дисплеем Брайля, вы можете обнаружить, что длинные абзацы обрезаются при прокрутке вперёд с помощью клавиш навигации вашего дисплея. На команду чтения текущего абзаца это также влияет. Это ошибка в обработке JAWS текстового элемента управления RICHEDIT50W, а не в самом Paperback, и для её исправления потребовалось довольно много времени, учитывая нежелание компании Vispero отвечать на проблемы с открытым исходным кодом.

Обходной путь, в конце концов найденный через группу обсуждения JAWS после месяцев ожидания, — это отредактировать `paperback.jcf` и установить значение "Braille Presentation and Panning" на "Always use DOM if available". Вам также стоит включить "Pan Text by Paragraph", иначе ваш дисплей будет оставаться на активном абзаце вместо продвижения вперёд. При обоих включённых параметрах прокрутка должна работать корректно.

## Поддерживаемые типы файлов

Paperback поддерживает следующие форматы и расширения:

* CHM файлы справки (`.chm`)
* DAISY книги (`.opf`, `.zip`)
* EPUB книги (`.epub`)
* FB2 электронные книги (`.fb2`)
* HTML документы (`.htm`, `.html`, `.xhtml`)
* Markdown документы (`.md`, `.markdown`, `.mdx`, `.mdown`, `.mdwn`, `.mkd`, `.mkdn`, `.mkdown`, `.ronn`)
* Документы Microsoft Word (`.docx`, `.docm`, `.doc`)
* MOBI/Kindle книги (`.mobi`, `.azw`, `.azw3`)
* Презентации OpenDocument (`.odp`, `.fodp`)
* Текстовые файлы OpenDocument (`.odt`, `.fodt`)
* PDF документы (`.pdf`)
* Презентации PowerPoint (`.pptx`, `.pptm`, `.ppt`)
* RTF документы (`.rtf`)
* Текстовые файлы и файлы журналов (`.txt`, `.log`)

* `P`: следующая страница.

### Дополнительные клавиши для вида документа

* `Delete` / `Numpad Delete` на управлении вкладками: закрыть выбранную вкладку документа.

* `Shift+F10` или клавиша Menu/Application в тексте документа: открыть контекстное меню.

## История изменений

### Версия 0.9.2
* Аудиокниги больше не заставляют программу чтения с экрана произносить серию пробелов при фокусировке на текстовом поле.
* Аудиокниги теперь называют файл по мере того, как вы переходите по ним по разделам.
* Аудиокниги теперь сообщают реальную длительность вместо того, чтобы утверждать, что каждый файл в них длится 24 часа.
* Закрытие веб-представления с помощью Escape больше не выводит отладочное предупреждение после перехода по ссылке внутри него.
* Копирование после выделения всего теперь дает вам весь документ вместо только загруженной части.
* Поиск теперь переходит сразу на найденную строку вместо того, чтобы заставлять программу чтения с экрана заново читать окно по мере возврата фокуса на книгу.
* Исправлены EPUB-файлы с блуждающим блоком ZIP64, отказывающиеся открываться с сообщением об ошибке "Invalid local file header".
* Исправлены длинные документы, возвращавшиеся в начало при непрерывном чтении программой чтения с экрана.
* Ссылки в веб-представлении теперь переводят вас в указываемый раздел вместо того, чтобы выдавать ошибку "File not found".
* Автоматическое объявление "Document reloaded" больше не прерывает программу чтения с экрана посередине предложения, а вместо этого ждет, пока она закончит.
* На вкладке General в диалоговом окне Settings теперь проходит фокус через параметры в порядке их отображения на экране, с каналом обновления непосредственно после опции проверки обновлений.
* Windows теперь всегда будет показывать "Paperback" в меню "Открыть с помощью" вместо полного девиза программы.
* Word Count и Document Info теперь показывают, сколько файлов содержит аудиокнига и какова ее общая продолжительность.

* Книги DAISY теперь воспроизводят свой звук на macOS вместо того, чтобы открываться и отслеживать временную шкалу в тишине.
* Исправлено исчезновение фигурных кавычек, длинных тире и подобных символов из документов RTF, слияние окружающих слов.
* Исправлена утечка необработанных данных изображений RTF в документ как искаженный текст.
* Исправлено сохранение устаревших записей в подменю недавних документов до происшествия, вызывающего его перестроение.
* Клавиатурные акселераторы вернулись во все переводы, поэтому русские меню снова имеют доступ с клавиатуры.
* Большие документы CHM теперь открываются в семь раз быстрее.
* Открытые документы теперь регистрируются в Windows, поэтому они отображаются в списке быстрого доступа панели задач и в списке недавних файлов меню "Пуск".
* Options переименован на Settings в соответствии с мобильными приложениями и, на macOS, с соглашением платформы.
* Paperback теперь запоминает положение, размер окна и состояние максимизации между запусками.
* Формы множественного числа теперь переводятся, поэтому сообщения, которые считают предметы, правильно читаются на языках, требующих более одной формы.
* Выбор ncc.html книги DAISY теперь открывает полную аудиокнигу вместо только текста.
* Названия действий в диалоговом окне Customize Keyboard Shortcuts теперь можно переводить.
* Название документа теперь стоит в начале строки заголовка, поэтому открытые книги можно различить на панели задач и в Alt+Tab.
* Диалоговое окно обновления теперь переведено.

### Версия 0.9.0

#### Добавлено

##### Общие
* CLI-инструмент с именем pb для быстрого преобразования любого поддерживаемого Paperback формата в HTML, Markdown или простой текст.
* Опция для перезагрузки документов, которые были изменены другими программами на диске.
* Опция "View Source" для открытия исходного кода документа в новой вкладке, полезная например для редактирования Markdown.
* Текст документа теперь разбивается на страницы, что означает, что вы можете загружать книги с десятками миллионов слов всего за пару секунд. Пожалуйста, сообщайте о любых странностях, обнаруженных при этом.

##### Поддержка платформ
* Поддержка ARM64 Windows!
* Встроенная поддержка macOS!
* Переключение полноэкранного режима.

##### Диалоговое окно "Все документы"
* Кнопка поиска для поиска отсутствующих книг, которые просто изменили свой путь.
* Фильтр статуса и строка состояния, поэтому вы можете фильтровать по статусу документа и видеть, сколько документов показано и выбрано.
* Ярлык `Ctrl+Shift+A` для снятия выделения со всех документов.

##### Параметры и читаемость
* Вкладка читаемости со следующими опциями:
    * Переносить слова (перемещено из общих);
    * Отображать таблицы встроенными (новое в этом выпуске, см. ниже);
    * Шрифт;
    * Цвет фона;
    * Интерлиньяж;
    * Интервал между абзацами;
    * Межбуквенный интервал;
    * Выравнивание текста.
* Пункт меню переноса слов и связанный с ним ярлык.
* Переключатель для определения того, как вы хотите отображать таблицы, и унифицированное отображение таблиц в документах.

##### Навигация
* Поддержка навигации по контейнеру.
* Опция для автоматического перемещения курсора в начало строки при навигации между строками, аналогично режиму просмотра в программах чтения с экрана.
* Клавиатурный ярлык equals для объявления вашего текущего процента в документе.

##### Закладки
* Временные закладки: вы можете иметь одну на документ, и они сохраняются. Используйте slash для установки и backslash для перехода к ней.

* Приблизительное время чтения в диалоговом окне подсчета слов, а также возможность установить скорость чтения, чтобы сделать эту метрику действительно полезной.
* Если при открытии диалогового окна подсчета слов активно выделение, будет показано, сколько слов вы выбрали.

##### Клавиатурные ярлыки
* Возможность настроить каждый клавиатурный ярлык в приложении через простой диалог.
* Настраиваемый клавиатурный ярлык для восстановления Paperback из системного лотка.

##### Языки
* Нидерландский, финский и польский.

##### Экспорт
* Расширенный пункт меню экспорта, позволяющий экспортировать в HTML и Markdown в дополнение к простому тексту.

##### Обновление
* Кнопка отмены в диалоговом окне текущего обновления.

##### Веб-представление
* Веб-представление теперь открывается в вашей текущей позиции чтения.

* Поддержка книг DAISY 2.0.

* Исправлено то, что некоторые элементы меню не отключались при отсутствии открытых документов.
* Исправлена ориентация ползунка go to percent.
* Исправлено оглавление в книгах Epub с кодированными URL-адресом путями файлов и/или идентификаторами фрагментов.
* Исправлено удаление пробелов из заголовков XHTML странным образом.

* Переключились на библиотеку zip, чтобы позволить открывать более широкий массив книг epub.

* Оглавление в книгах Epub теперь будет сохранено точно.
* Unicode неразрывный пробел теперь учитывается при удалении пустых строк.
* Вам больше не будет задавался вопрос о том, как вы хотите открыть неопознанный файл каждый раз, когда его загружаете, только в первый раз.

### Версия 0.4.0
* Добавлена поддержка файлов CHM!
* Добавлена поддержка закладок! Вы можете иметь столько закладок сколько вы хотите во всех документах. Вы можете перемещаться вперед и назад через них с b и shift+b, установить один с control+shift+b, и открыть диалог для перехода к определенной закладке с control+b.
* Добавлен установщик вместе с портативным zip-файлом! Установщик будет устанавливать Paperback в каталог Program Files и автоматически устанавливать связи файлов для вас.
* Текстовые файлы с BOM теперь должны правильно декодироваться, и BOM больше не будет отображаться в начале текста.
* Добавлено гораздо больше информации в строку состояния. Теперь она показывает вашу текущую строку, символ и процент чтения.
* Комментарии HTML а также содержимое тегов script и style больше не будут показываться в текстовом выводе.
* Если вы передаете относительный путь Paperback в командной строке, он теперь будет правильно разрешен.
* Перемещение процентов теперь обрабатывается отдельным диалогом на основе ползунка, доступным с control+shift+g.
* Документы без известных названий или авторов теперь всегда будут иметь значение по умолчанию.
* Логика сохранения позиции теперь намного умнее и должна только писать на диск когда абсолютно необходимо.
* Документ, на котором вы были сосредоточены при закрытии Paperback, теперь запоминается при перезапуске приложения.
* Входные данные в диалоги go to line и go to page теперь должны быть более строго санированы.
* Исправлена навигация оглавления в книгах epub 3 с относительными путями в их манифестах.
