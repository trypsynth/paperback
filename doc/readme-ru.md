# Paperback - версия 0.9.2

## Введение

Paperback — это легкая, быстрая и доступная программа для чтения электронных книг и документов для всех, от случайных читателей до опытных пользователей. Она разработана с учетом доступности программ чтения с экрана, высокой скорости и отсутствия лишних функций.

## Системные требования

Paperback в настоящее время работает на Windows 10/11 и всех современных версиях ARM macOS. Нативные приложения для iOS и Android находятся в активной разработке, с общедоступными тестовыми сборками, запланированными вскоре после выпуска настольной версии 0.9.0, перед единым выпуском версии 1.0 для всех четырех платформ.

## Возможности

* Полностью самостоятельная программа, не требующая установки какого-либо другого программного обеспечения на ваш компьютер для начала чтения.
* Невероятно быстрая, даже на старом оборудовании.
* Простой интерфейс с вкладками, позволяющий открывать столько документов, сколько вы хотите, рядом друг с другом.
* Сохраняет вашу точную позицию чтения для каждого открытого документа.
* При желании запоминает, какие документы были открыты при закрытии программы, и восстанавливает их при следующем запуске.
* Включает функциональность навигации, аналогичную той, которая встречается в режиме веб-просмотра многих программ чтения с экрана, для быстрой и простой навигации по документам.
* Включает надежный диалог поиска с такими функциями, как история и поддержка регулярных выражений.
* Может работать полностью портативно или устанавливаться с автоматической настройкой ассоциаций файлов.
* Поддерживает огромный массив распространенных форматов файлов.

## Совместимость с программами чтения с экрана

Paperback хорошо работает со всеми основными программами чтения с экрана. Однако известна одна проблема для пользователей JAWS.

### JAWS и брайлевские дисплеи

Если вы используете JAWS с брайлевским дисплеем, вы можете обнаружить, что длинные абзацы обрезаются при прокрутке вперед с помощью клавиш навигации дисплея. На эту проблему также влияет команда чтения текущего абзаца. Это ошибка в обработке текстового элемента управления RICHEDIT50W в JAWS, а не в самом Paperback, и исправление ее заняло довольно много времени учитывая неохотное отношение компании Vispero к решению проблем с открытым исходным кодом.

Обходной путь, который был в итоге найден в группе обсуждения JAWS после месяцев ожидания, — это отредактировать `paperback.jcf` и установить "Braille Presentation and Panning" на "Always use DOM if available". Вы также захотите включить "Pan Text by Paragraph", иначе ваш дисплей останется на активном абзаце вместо продвижения вперед. При наличии обоих параметров прокрутка должна работать правильно.

## Поддерживаемые форматы файлов

Paperback поддерживает следующие форматы и расширения:

* Файлы справки CHM (`.chm`)
* Книги DAISY (`.opf`, `.zip`)
* Книги EPUB (`.epub`)
* Электронные книги FB2 (`.fb2`)
* Документы HTML (`.htm`, `.html`, `.xhtml`)
* Документы Markdown (`.md`, `.markdown`, `.mdx`, `.mdown`, `.mdwn`, `.mkd`, `.mkdn`, `.mkdown`, `.ronn`)
* Документы Microsoft Word (`.docx`, `.docm`, `.doc`)
* Аудиокниги M4B (`.m4b`)
* Книги MOBI/Kindle (`.mobi`, `.azw`, `.azw3`)
* Презентации OpenDocument (`.odp`, `.fodp`)
* Текстовые файлы OpenDocument (`.odt`, `.fodt`)
* Документы PDF (`.pdf`)
* Презентации PowerPoint (`.pptx`, `.pptm`, `.ppt`)
* Документы RTF (`.rtf`)
* Обычные текстовые файлы и файлы журналов (`.txt`, `.log`)

Paperback разработан с приоритетом клавиатурного ввода. Ниже приведены текущие горячие клавиши.

* `Ctrl+O`: Открыть документ.
* `Ctrl+F4` (macOS: `Cmd+W`): Закрыть текущий документ.
* `Ctrl+Shift+F4` (macOS: `Cmd+Shift+W`): Закрыть все открытые документы.
* `Ctrl+Shift+T`: Открыть заново последний закрытый документ.
* `Ctrl+R`: Показать диалог "Все документы" (из последних документов).
* `Ctrl+Q`: Выход (только Windows; на macOS это находится в меню приложения).

* `Ctrl+P`: Перейти на страницу (если поддерживается текущим документом).
* `=`: Объявить текущий процент чтения.

* `Alt+Right` (macOS: `Cmd+]`): Перейти вперед в истории навигации.
* `[`: Предыдущий раздел.
* `]`: Следующий раздел.
* `Shift+H`: Предыдущий заголовок.
* `H`: Следующий заголовок.
* `Shift+1` по `Shift+6`: Предыдущий заголовок уровня 1-6.
* `1` по `6`: Следующий заголовок уровня 1-6.
* `Shift+P`: Предыдущая страница.
* `P`: Следующая страница.
* `Shift+B`: Предыдущая закладка.
* `B`: Следующая закладка.
* `/`: Установить временную закладку.
* `\`: Перейти к временной закладке.
* `Shift+N`: Предыдущее примечание.
* `N`: Следующее примечание.
* `Ctrl+B`: Перейти ко всем закладкам и примечаниям.
* `Ctrl+Alt+B`: Перейти только к закладкам.
* `Ctrl+Alt+M`: Перейти только к примечаниям.
* `Ctrl+Shift+W` (macOS: `RawCtrl+Shift+W`, то есть физическая клавиша Control, а не Cmd): Просмотреть текст примечания в текущей позиции.
* `Shift+K`: Предыдущая ссылка.
* `K`: Следующая ссылка.
* `Shift+G`: Предыдущее изображение.
* `G`: Следующее изображение.
* `Shift+F`: Предыдущий рисунок.
* `F`: Следующий рисунок.
* `Shift+T`: Предыдущая таблица.
* `T`: Следующая таблица.
* `Shift+S`: Предыдущий разделитель.
* `S`: Следующий разделитель.
* `Shift+L`: Предыдущий список.
* `L`: Следующий список.
* `Shift+I`: Предыдущий элемент списка.
* `I`: Следующий элемент списка.
* `Shift+,`: Перейти в начало текущего контейнера (список или таблица).
* `,`: Перейти за конец текущего контейнера (список или таблица).

### Меню "Инструменты"

* `Ctrl+W` (macOS: `RawCtrl+W`, то есть физическая клавиша Control, а не Cmd): Показать количество слов в текущем документе.
* `Ctrl+I`: Показать информацию о документе.
* `Ctrl+T`: Показать оглавление.
* `F7`: Показать список элементов.
* `Ctrl+Shift+C`: Открыть содержащую папку.
* `Ctrl+Shift+V`: Открыть текущий контент в веб-просмотр.
* `Ctrl+U`: Просмотреть источник документа на новой вкладке.

### Меню "Справка"

* `Ctrl+F1`: Показать диалог "О программе".
* `F1`: Просмотреть справку в браузере по умолчанию.
* `Shift+F1`: Просмотреть справку в Paperback.
* `Ctrl+Shift+U`: Проверить обновления.
* `Ctrl+D`: Открыть страницу пожертвований в браузере по умолчанию.

### Дополнительные клавиши просмотра документа

* `Delete` / `Numpad Delete` в элементе управления вкладки: Закрыть выбранную вкладку документа.
* `Enter` или `Space` в тексте документа: Активировать ссылку у курсора или открыть табличный вид на маркере таблицы.
* `Shift+F10` или клавиша Menu/Application в тексте документа: Открыть контекстное меню.

## Журнал изменений

### Версия 0.9.2
* Аудиокниги больше не заставляют программу чтения с экрана воспроизводить серию пробелов при фокусировке на текстовое поле.
* Аудиокниги теперь называют файл, когда вы переходите через разделы.
* Аудиокниги теперь сообщают их реальную длительность вместо того, чтобы утверждать, что каждый файл длится 24 часа.
* Закрытие веб-представления с помощью Escape больше не выызывает отладочное предупреждение после перехода по ссылке внутри.
* Копирование после выделения всего теперь дает вам весь документ вместо только загруженной части.
* Find теперь переходит прямо на найденную строку вместо того, чтобы заставлять программу чтения с экрана читать окно заново при возврате фокуса в книгу.
* Исправлены EPUB файлы с блуждающим блоком ZIP64, отказывающиеся открываться с ошибкой "Invalid local file header".
* Исправлены длинные документы, возвращающиеся в начало при непрерывном чтении программой чтения с экрана.
* Ссылки в WebView теперь переводят вас в раздел, на который они указывают, вместо ошибки "File not found".
* Автоматическое объявление "Document reloaded" больше не прерывает программу чтения с экрана в середине предложения, а ждет, пока она закончит говорить.
* Вкладка General в диалоге Settings теперь переходит по опциям в порядке их появления на экране, с каналом обновления прямо после опции проверки обновлений.
* Windows теперь всегда показывает "Paperback" в меню Open With вместо полного девиза программы.
* Word Count и Document Info теперь показывают, сколько файлов содержит аудиокнига и как долго она длится в целом.
