# Paperback - версия 0.9.2

## Введение

Paperback — это легкая, быстрая и доступная программа для чтения электронных книг и документов для всех, от случайных читателей до опытных пользователей. Она разработана с учетом совместимости с программами экранного доступа, высокой скорости работы и отсутствия лишних функций.

## Системные требования

Paperback в настоящее время работает на Windows 10/11 и всех современных версиях ARM macOS. Нативные приложения для iOS и Android находятся в активной разработке, с публичными тестовыми сборками, запланированными вскоре после выпуска версии 0.9.0 для настольных компьютеров, перед единым выпуском версии 1.0, охватывающим все четыре платформы.

## Особенности

* Полностью автономное приложение, не требующее установки дополнительного ПО на ваш компьютер для начала чтения.
* Невероятно быстрое, даже на старом оборудовании.
* Простой интерфейс с вкладками, позволяющий открывать столько документов, сколько вам нужно, рядом друг с другом.
* Сохраняет вашу точную позицию чтения для каждого открытого документа.
* Может запомнить, какие документы были открыты при закрытии программы, и восстановить их при следующем запуске.
* Включает функции навигации, похожие на те, которые встречаются в режиме веб-поиска многих программ экранного доступа, для быстрой и удобной навигации по документам.
* Включает надежный диалог поиска с функциями, такими как история и поддержка регулярных выражений.
* Может работать полностью портативно или быть установлена с автоматической настройкой связей между файлами и приложением.
* Поддерживает огромный набор распространенных форматов файлов.

## Совместимость с программами экранного доступа

Paperback хорошо работает со всеми основными программами экранного доступа. Однако есть одна известная проблема для пользователей JAWS.

### JAWS и дисплеи Брайля

Если вы используете JAWS с дисплеем Брайля, вы можете обнаружить, что длинные абзацы усекаются при перелистывании вперед с помощью клавиш навигации вашего дисплея. Команда чтения текущего абзаца также затронута. Это ошибка в обработке JAWS текстового элемента управления RICHEDIT50W, а не что-то в самом Paperback, и ошибка, для исправления которой потребовалось немало времени, учитывая энтузиазм Vispero к реагированию на проблемы с открытым исходным кодом.

Обходной путь, в конце концов выявленный через группу обсуждения JAWS после месяцев ожидания, заключается в редактировании `paperback.jcf` и установке параметра «Braille Presentation and Panning» на «Always use DOM if available». Вы также захотите включить «Pan Text by Paragraph», иначе ваш дисплей будет оставаться на активном абзаце вместо продвижения вперед. При обоих включенных параметрах перелистывание должно работать правильно.

## Поддерживаемые форматы файлов

Paperback поддерживает следующие форматы и расширения:

* Архивы комиксов (`.cbz`, `.cbr`)
* CHM файлы справки (`.chm`)
* DAISY книги (`.opf`, `.zip`)
* EPUB книги (`.epub`)
* FB2 электронные книги (`.fb2`)
* HTML документы (`.htm`, `.html`, `.xhtml`)
* Справочные страницы, как `man`, так и BSD `mdoc` (`.1` по `.9`, `.man`, `.roff` и сжатые версии каждого)
* Markdown документы (`.md`, `.markdown`, `.mdx`, `.mdown`, `.mdwn`, `.mkd`, `.mkdn`, `.mkdown`, `.ronn`)
* Документы Microsoft Word (`.docx`, `.docm`, `.doc`)
* M4B аудиокниги (`.m4b`)
* MOBI/Kindle книги (`.mobi`, `.azw`, `.azw3`)
* OpenDocument презентации (`.odp`, `.fodp`)
* OpenDocument текстовые файлы (`.odt`, `.fodt`)
* PDF документы (`.pdf`)
* PowerPoint презентации (`.pptx`, `.pptm`, `.ppt`)
* RTF документы (`.rtf`)
* WinHelp файлы (`.hlp`)
* Простые текстовые файлы и логи (`.txt`, `.log`)

## Клавиатурные сокращения

Paperback разработан для работы с использованием клавиатуры в приоритете. Вот текущие сокращения.

Сокращения ниже указаны для Windows. Если macOS отличается, эквивалент указан в скобках — в основном потому, что Ctrl+G, Ctrl+W и Alt+Left/Right уже используются другими системными или программными соглашениями на этой платформе.

### Меню "Файл"

* `Ctrl+O`: Открыть документ.
* `Ctrl+F4` (macOS: `Cmd+W`): Закрыть текущий документ.
* `Ctrl+Shift+F4` (macOS: `Cmd+Shift+W`): Закрыть все открытые документы.
* `Ctrl+Shift+T`: Снова открыть последний закрытый документ.
* `Ctrl+R`: Показать диалог "Все документы" (из недавних документов).
* `Ctrl+Q`: Выход (только в Windows; в macOS это находится в меню приложения).

* `Ctrl+F`: Показать диалог поиска.
* `F3` (macOS: `Cmd+G`): Найти следующее.

* `Ctrl+P`: Перейти к странице (если поддерживается текущим документом).
* `=`: Объявить ваш текущий процент прочитанного и номер страницы, например "15%, страница 30". Номер страницы пропускается для документов без номеров страниц.
* `Alt+Left` (macOS: `Cmd+[`): Вернуться в истории навигации.
* `Alt+Right` (macOS: `Cmd+]`): Перейти вперёд в истории навигации.
* `[`: Предыдущий раздел.
* `]`: Следующий раздел.
* `Shift+H`: Предыдущий заголовок.
* `H`: Следующий заголовок.
* `Shift+1` до `Shift+6`: Предыдущий заголовок уровня 1-6.
* `1` до `6`: Следующий заголовок уровня 1-6.
* `Shift+P`: Предыдущая страница.
* `P`: Следующая страница.
* `Shift+B`: Предыдущая закладка.
* `B`: Следующая закладка.
* `/`: Установить вашу временную закладку.
* `\`: Перейти к вашей временной закладке.
* `Shift+N`: Предыдущая заметка.
* `N`: Следующая заметка.
* `Ctrl+B`: Перейти ко всем закладкам и заметкам.
* `Ctrl+Alt+B`: Перейти только к закладкам.
* `Ctrl+Alt+M`: Перейти только к заметкам.
* `Ctrl+Shift+W` (macOS: `RawCtrl+Shift+W`, то есть физическая клавиша Control, а не Cmd): Просмотреть текст заметки в текущей позиции.
* `Shift+K`: Предыдущая ссылка.
* `K`: Следующая ссылка.
* `Shift+G`: Предыдущее изображение.
* `G`: Следующее изображение.
* `Shift+F`: Предыдущий рисунок.
* `F`: Следующий рисунок.
* `Shift+T`: Предыдущая таблица.
* `T`: Следующая таблица.
* `Shift+S`: Предыдущий разделитель.
* `S`: Следующий разделитель.
* `Shift+L`: Предыдущий список.
* `L`: Следующий список.
* `Shift+I`: Предыдущий элемент списка.
* `I`: Следующий элемент списка.
* `Shift+,`: Перейти в начало текущего контейнера (список или таблица).
* `,`: Перейти за конец текущего контейнера (список или таблица).

### Меню "Инструменты"

* `Ctrl+W` (macOS: `RawCtrl+W`, то есть физическая клавиша Control, а не Cmd): Показать количество слов в текущем документе.
* `Ctrl+I`: Показать информацию о документе.
* `Ctrl+T`: Показать оглавление.
* `F7`: Показать список элементов.
* `Ctrl+Shift+C`: Открыть содержащую папку.
* `Ctrl+Shift+V`: Открыть текущий контент в Web View.
* `Ctrl+U`: Просмотреть исходный код документа в новой вкладке.

* `;`: Перемотать звуковое повествование назад.

### Меню "Справка"

* `Ctrl+F1`: Показать диалог "О программе".
* `F1`: Просмотреть справку в вашем браузере по умолчанию.
* `Shift+F1`: Просмотреть справку в Paperback.
* `Ctrl+Shift+U`: Проверить обновления.
* `Ctrl+D`: Открыть страницу пожертвований в вашем браузере по умолчанию.

### Дополнительные клавиши представления документа

* `Delete` / `Numpad Delete` на элементе управления вкладкой: Закрыть выбранную вкладку документа.
* `Enter` или `Space` в тексте документа: Активировать ссылку на курсоре или открыть представление таблицы при нахождении на маркере таблицы.
* `Shift+F10` или клавиша Menu/Application в тексте документа: Открыть контекстное меню.

## Журнал изменений

### Версия 0.9.2
* Аудиокниги больше не заставляют экранный диктор прочитывать серию пробелов при фокусировке на текстовом поле.
* Аудиокниги теперь называют файл при пошаговом просмотре разделов.
* Аудиокниги теперь сообщают реальную длительность вместо того, чтобы утверждать, что каждый файл длится 24 часа.
* Закрытие Web View с помощью Escape больше не выводит отладочное предупреждение после переход по ссылке внутри.
* Копирование после Select All теперь дает весь документ вместо только загруженной части.
* Find теперь переходит прямо к найденной строке вместо повторного прочитывания окна экранным диктором при возврате фокуса в книгу.
* Исправлены файлы EPUB с посторонним блоком ZIP64, которые отказывались открываться с ошибкой "Invalid local file header".
* Исправлены длинные документы, которые возвращались в начало при непрерывном чтении экранным диктором.
* Ссылки в WebView теперь переводят вас в раздел, на который они указывают, вместо ошибки "File not found".
* Сочетание клавиш `=` теперь объявляет как страницу, так и процент, например, "15%, page 30", и остается неизменным для документов без номеров страниц.
* Автоматическое объявление "Document reloaded" больше не прерывает экранный диктор на середине предложения, а вместо этого ждет завершения его речи.
* Вкладка General в диалоговом окне Settings теперь перемещается по опциям в порядке их появления на экране, с каналом обновления непосредственно после опции проверки обновлений.
* При обновлении перезапущенное окно теперь выводится на передний план вместо того, чтобы оставаться позади всех остальных окон в Alt+Tab.
* В меню Open With теперь всегда отображается "Paperback" вместо полного девиза программы.
* Word Count и Document Info теперь показывают, сколько файлов содержит аудиокнига и сколько времени она занимает.

### Версия 0.9.1
* Звуки закладок и заметок теперь воспроизводятся на macOS.
* Аудиокниги DAISY теперь воспроизводят звук на macOS вместо открытия и отслеживания временной шкалы в молчании.
* Исправлены фигурные кавычки, длинные тире и подобные символы, исчезавшие из документов RTF, объединяя окружающие слова.
* Исправлены изображения RTF, утекающие свои необработанные данные в документ в виде искаженного текста.
* Исправлено подменю Recent Documents, которое сохраняло устаревшие записи до тех пор, пока что-то еще не произойдет для его перестроения.
* Клавиатурные акселераторы вернулись во все переводы, поэтому русские меню снова имеют доступ с клавиатуры.
* Большие документы CHM теперь открываются в 7 раз быстрее.
* Открытые документы теперь регистрируются в Windows, поэтому они появляются в списке перехода панели задач и в списке недавних документов меню "Пуск".
* Options переименовано на Settings, что соответствует мобильным приложениям и, на macOS, соглашению платформы.
* Paperback теперь запоминает положение, размер и состояние развернутого окна между запусками.
* Множественные формы теперь переводятся, поэтому сообщения, которые считают вещи, правильно читаются на языках, требующих более одной формы.
* Выбор файла ncc.html книги DAISY теперь открывает полную аудиокнигу вместо только ее текста.
* Имена действий в диалоговом окне Customize Keyboard Shortcuts теперь можно переводить.
* Заголовок документа теперь стоит на первом месте в заголовке окна, поэтому открытые книги можно различить на панели задач и в Alt+Tab.
* Диалог обновления теперь переведен.

### Версия 0.9.0

#### Добавлено

##### Общее
* Инструмент CLI под названием pb для быстрого преобразования любого из поддерживаемых Paperback форматов в HTML, Markdown или простой текст.

##### Поддержка платформы
* Поддержка ARM64 Windows!
* Встроенная поддержка macOS!
* Переключатель полноэкранного режима.

##### Диалог All Documents
* Кнопка поиска для поиска потерянных книг, которые только что изменили свой путь.

* Возможность настраивать каждое клавиатурное сочетание в приложении через простой диалог.
* Настраиваемое клавиатурное сочетание для восстановления Paperback из системного лотка.

* Нидерландский, финский и польский.
