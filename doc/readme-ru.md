# Paperback - версия 0.9.2

## Введение

Paperback — это легкая, быстрая и доступная программа для чтения электронных книг и документов для всех, от случайных читателей до опытных пользователей. Она разработана с учетом совместимости с программами экранного доступа, высокой скорости работы и отсутствия лишних функций.

## Системные требования

Paperback в настоящее время работает на Windows 10/11 и всех современных версиях ARM macOS. Нативные приложения для iOS и Android находятся в активной разработке, с публичными тестовыми сборками, запланированными вскоре после выпуска версии 0.9.0 для настольных компьютеров, перед единым выпуском версии 1.0, охватывающим все четыре платформы.

## Особенности

* Полностью автономное приложение, не требующее установки дополнительного ПО на ваш компьютер для начала чтения.
* Невероятно быстрое, даже на старом оборудовании.
* Простой интерфейс с вкладками, позволяющий открывать столько документов, сколько вам нужно, рядом друг с другом.
* Сохраняет вашу точную позицию чтения для каждого открытого документа.
* Может запомнить, какие документы были открыты при закрытии программы, и восстановить их при следующем запуске.
* Включает функции навигации, похожие на те, которые встречаются в режиме веб-поиска многих программ экранного доступа, для быстрой и удобной навигации по документам.
* Включает надежный диалог поиска с функциями, такими как история и поддержка регулярных выражений.
* Может работать полностью портативно или быть установлена с автоматической настройкой связей между файлами и приложением.
* Поддерживает огромный набор распространенных форматов файлов.

## Совместимость с программами экранного доступа

Paperback хорошо работает со всеми основными программами экранного доступа. Однако есть одна известная проблема для пользователей JAWS.

### JAWS и дисплеи Брайля

Если вы используете JAWS с дисплеем Брайля, вы можете обнаружить, что длинные абзацы усекаются при перелистывании вперед с помощью клавиш навигации вашего дисплея. Команда чтения текущего абзаца также затронута. Это ошибка в обработке JAWS текстового элемента управления RICHEDIT50W, а не что-то в самом Paperback, и ошибка, для исправления которой потребовалось немало времени, учитывая энтузиазм Vispero к реагированию на проблемы с открытым исходным кодом.

Обходной путь, в конце концов выявленный через группу обсуждения JAWS после месяцев ожидания, заключается в редактировании `paperback.jcf` и установке параметра «Braille Presentation and Panning» на «Always use DOM if available». Вы также захотите включить «Pan Text by Paragraph», иначе ваш дисплей будет оставаться на активном абзаце вместо продвижения вперед. При обоих включенных параметрах перелистывание должно работать правильно.

## Поддерживаемые типы файлов

Paperback поддерживает следующие форматы и расширения:

* Файлы справки CHM (`.chm`)
* Книги DAISY (`.opf`, `.zip`)
* Книги EPUB (`.epub`)
* Электронные книги FB2 (`.fb2`)
* Документы HTML (`.htm`, `.html`, `.xhtml`)
* Документы Markdown (`.md`, `.markdown`, `.mdx`, `.mdown`, `.mdwn`, `.mkd`, `.mkdn`, `.mkdown`, `.ronn`)
* Документы Microsoft Word (`.docx`, `.docm`, `.doc`)
* Аудиокниги M4B (`.m4b`)
* Книги MOBI/Kindle (`.mobi`, `.azw`, `.azw3`)
* Презентации OpenDocument (`.odp`, `.fodp`)
* Текстовые файлы OpenDocument (`.odt`, `.fodt`)
* Документы PDF (`.pdf`)
* Презентации PowerPoint (`.pptx`, `.pptm`, `.ppt`)
* Документы RTF (`.rtf`)
* Простые текстовые файлы и логи (`.txt`, `.log`)

## Сочетания клавиш

Paperback разработан для использования в первую очередь с клавиатурой. Здесь приведены текущие сочетания клавиш.

Сочетания клавиш ниже предназначены для Windows. Если macOS отличается, эквивалент указан в скобках — в основном потому, что Ctrl+G, Ctrl+W и Alt+Left/Right уже зарезервированы другими системными соглашениями или соглашениями приложений на этой платформе.

### Меню "Файл"

* `Ctrl+O`: открыть документ.
* `Ctrl+F4` (macOS: `Cmd+W`): закрыть текущий документ.
* `Ctrl+Shift+F4` (macOS: `Cmd+Shift+W`): закрыть все открытые документы.
* `Ctrl+Shift+T`: открыть последний закрытый документ.
* `Ctrl+R`: показать диалог "Все документы" (из недавних документов).
* `Ctrl+Q`: выход (только Windows; на macOS это находится в меню приложения).

### Меню "Перейти"

* `F3` (macOS: `Cmd+G`): найти следующий результат.

* `Ctrl+G` (macOS: `Cmd+L`): перейти на строку.
* `Ctrl+Shift+G` (macOS: `Cmd+Shift+L`): перейти на процент.
* `Ctrl+P`: перейти на страницу (если поддерживается текущим документом).
* `=`: объявить ваш текущий процент прочитанного.
* `Alt+Left` (macOS: `Cmd+[`): вернуться в истории навигации.
* `Alt+Right` (macOS: `Cmd+]`): перейти вперед в истории навигации.
* `[`: предыдущий раздел.
* `]`: следующий раздел.
* `Shift+H`: предыдущий заголовок.
* `H`: следующий заголовок.
* `Shift+1` через `Shift+6`: предыдущий заголовок уровня 1-6.
* `1` через `6`: следующий заголовок уровня 1-6.
* `Shift+P`: предыдущая страница.
* `P`: следующая страница.
* `Shift+B`: предыдущая закладка.
* `B`: следующая закладка.
* `/`: установить временную закладку.
* `\`: перейти к временной закладке.
* `Shift+N`: предыдущее примечание.
* `N`: следующее примечание.
* `Ctrl+B`: перейти ко всем закладкам и примечаниям.
* `Ctrl+Alt+B`: перейти только к закладкам.
* `Ctrl+Alt+M`: перейти только к примечаниям.
* `Ctrl+Shift+W` (macOS: `RawCtrl+Shift+W`, т. е. физическая клавиша Control вместо Cmd): показать текст примечания в текущей позиции.
* `Shift+K`: предыдущая ссылка.
* `K`: следующая ссылка.
* `Shift+G`: предыдущее изображение.
* `G`: следующее изображение.
* `Shift+F`: предыдущий рисунок.
* `F`: следующий рисунок.
* `Shift+T`: предыдущая таблица.
* `T`: следующая таблица.
* `Shift+S`: предыдущий разделитель.
* `S`: следующий разделитель.
* `Shift+L`: предыдущий список.
* `L`: следующий список.
* `Shift+I`: предыдущий элемент списка.
* `I`: следующий элемент списка.
* `Shift+,`: перейти в начало текущего контейнера (списка или таблицы).
* `,`: перейти за конец текущего контейнера (списка или таблицы).

### Меню "Инструменты"

* `Ctrl+W` (macOS: `RawCtrl+W`, т. е. физическая клавиша Control вместо Cmd): показать подсчет слов для текущего документа.
* `Ctrl+I`: показать информацию о документе.
* `Ctrl+T`: показать содержание.
* `F7`: показать список элементов.
* `Ctrl+Shift+C`: открыть содержащую папку.
* `Ctrl+Shift+V`: открыть текущее содержимое в Web View.
* `Ctrl+U`: просмотреть исходный код документа в новой вкладке.
* `Ctrl+Shift+E`: экспортировать данные документа (`.paperback`).
* `Ctrl+Shift+I`: импортировать данные документа (`.paperback`).
* `Ctrl+E`: экспортировать текущий документ в обычный текст.
* `Ctrl+Shift+B`: переключить закладку в текущей позиции выделения/курсора.

* `Ctrl+;`: уменьшить величину поиска в аудио.
* `F11` (macOS: `RawCtrl+Ctrl+F`, т. е. Control+Command+F): переключить полноэкранный режим.
* `Ctrl+,`: открыть параметры (macOS: Preferences, в меню приложения).
* `Ctrl+Shift+S`: переключить таймер сна.

### Меню "Справка"

* `Ctrl+F1`: показать диалог "О программе".
* `F1`: просмотреть справку в браузере по умолчанию.
* `Shift+F1`: просмотреть справку в Paperback.
* `Ctrl+Shift+U`: проверить обновления.
* `Ctrl+D`: открыть страницу пожертвований в браузере по умолчанию.

### Дополнительные клавиши в представлении документа

* `Delete` / `Numpad Delete` на элементе управления вкладками: закрыть выбранную вкладку документа.
* `Enter` или `Space` в тексте документа: активировать ссылку у курсора или открыть представление таблицы при нахождении на маркере таблицы.
* `Shift+F10` или клавиша Menu/Application в тексте документа: открыть контекстное меню.

## Журнал изменений

### Версия 0.9.2
* Аудиокниги больше не заставляют программу чтения с экрана читать подряд пробелы при фокусировке на текстовом поле.
* Аудиокниги теперь называют файл по мере продвижения по разделам.
* Аудиокниги теперь сообщают свою реальную длительность вместо того, чтобы заявлять, что каждый файл длится 24 часа.
* Закрытие веб-представления клавишей Escape больше не выводит диалог отладки после перехода по ссылке внутри него.
* При копировании после функции Select All теперь копируется весь документ, а не только загруженная его часть.
* Функция Find теперь сразу переходит к найденной строке, а не требует, чтобы программа чтения с экрана заново читала окно при возврате фокуса в книгу.
* Исправлена ошибка, при которой EPUB с блоком ZIP64 отказывался открываться с сообщением "Invalid local file header".
* Исправлена ошибка, при которой длинные документы возвращались в начало во время непрерывного чтения программой чтения с экрана.
* Ссылки в WebView теперь открывают нужный раздел вместо того, чтобы выводить ошибку "File not found".
* Автоматическое объявление "Document reloaded" больше не прерывает программу чтения с экрана на полуслове, вместо этого дожидаясь завершения фразы.
* Вкладка General диалога Settings теперь переключается между параметрами в том порядке, в котором они отображаются на экране, с канал обновления сразу после опции проверки обновлений.
* Windows теперь всегда показывает "Paperback" в меню "Open With" вместо полного девиза программы.
* Word Count и Document Info теперь показывают количество файлов в аудиокниге и её общую длительность.

### Версия 0.9.1
* Звуки закладок и заметок теперь воспроизводятся на macOS.
* Книги DAISY теперь воспроизводят аудио на macOS вместо открытия и отслеживания временной шкалы в тишине.
* Исправлена ошибка, при которой из RTF документов исчезали фигурные скобки, тире и похожие символы, объединяя окружающие слова.
* Исправлена ошибка утечки сырых данных RTF изображений в документ в виде искажённого текста.
* Исправлена ошибка, при которой подменю "Recent Documents" сохраняло устаревшие записи до тех пор, пока что-то не пересчитывало его.
* Клавиатурные ускорители теперь присутствуют в каждом переводе, поэтому русские меню снова имеют доступ с клавиатуры.
* Большие CHM документы теперь открываются в семь раз быстрее.
* Открытые документы теперь регистрируются в Windows, поэтому они появляются в списке переходов панели задач и в недавних файлах меню "Start".
* Options переименован на Settings в соответствии с мобильными приложениями и, на macOS, с соглашением платформы.
* Paperback теперь запоминает положение, размер и состояние окна между запусками.
* Формы множественного числа теперь переводятся, поэтому сообщения, которые считают элементы, правильно читаются на языках, требующих более одной формы.
* Выбор ncc.html книги DAISY теперь открывает полную аудиокнигу вместо только текста.
* Имена действий диалога Customize Keyboard Shortcuts теперь могут быть переведены.
* Название документа теперь находится в начале заголовка окна, поэтому открытые книги можно различить в панели задач и Alt+Tab.
* Диалог обновления теперь переведён.

### Версия 0.9.0

#### Добавлено

##### Общее
* Инструмент командной строки pb для быстрого преобразования любого поддерживаемого Paperback формата в HTML, Markdown или простой текст.
* Опция перезагрузки документов, которые были изменены другими программами на диске.
* Опция View Source для открытия исходного кода документа в новой вкладке, полезна, например, для редактирования Markdown.
* Текст документа теперь разбит на страницы, что означает, что вы можете загружать книги с десятками миллионов слов всего за пару секунд. Пожалуйста, сообщайте о любых найденных странностях.

##### Поддержка платформ
* Поддержка ARM64 Windows!
* Встроенная поддержка macOS!
* Переключение полноэкранного режима.

##### Диалог All Documents
* Кнопка для поиска пропавших книг, которые изменили путь.
* Фильтр статуса и строка состояния, позволяющие фильтровать по статусу документа и видеть, сколько документов показано и выбрано.
* Сочетание клавиш `Ctrl+Shift+A` для отмены выделения всех документов.

##### Параметры и читаемость
* Вкладка читаемости со следующими параметрами:
    * Перенос слов (перемещено из общих);
    * Вывод таблиц по строкам (новое в этом выпуске, см. ниже);
    * Шрифт;
    * Цвет фона;
    * Межстрочное расстояние;
    * Расстояние между абзацами;
    * Расстояние между буквами;
    * Выравнивание текста.
* Пункт меню переноса слов и соответствующая клавиша быстрого доступа.
* Переключатель для определения способа отображения таблиц и унифицированного отображения таблиц во всех документах.

##### Навигация
* Поддержка навигации по контейнерам.
* Опция для автоматического перемещения курсора в начало строки при навигации между строками, похожа на режим просмотра в программах чтения с экрана.
* Сочетание клавиш equals для объявления вашего текущего процента через документ.

##### Закладки
* Временные закладки: вы можете иметь одну на документ, и они сохраняются. Используйте косую черту для установки и обратную косую черту для перехода к ней.

##### Подсчёт слов
* Предполагаемое время чтения в диалоге подсчёта слов, а также возможность установки скорости чтения, чтобы этот показатель был действительно полезен.
* Если при открытии диалога подсчёта слов активно выделение, теперь будет показано количество выбранных слов.

##### Сочетания клавиш
* Возможность настройки всех сочетаний клавиш в приложении через простой диалог.
* Настраиваемое сочетание клавиш для восстановления Paperback из системного лотка.

##### Языки
* Нидерландский, финский и польский.

##### Экспорт
* Расширено меню экспорта для экспорта в HTML и Markdown в дополнение к простому тексту.

##### Средство обновления
* Кнопка отмены в диалоге выполняемого обновления.
* Средство обновления теперь проверяет, что загруженный файл не был изменён.

##### Веб-представление
* Веб-представление теперь открывается на вашей текущей позиции чтения.

##### Книги DAISY
* Поддержка книг DAISY 2.0.
* Поддержка воспроизведения аудио DAISY 2.02.

##### Аудиокниги

### Версия 0.4.0
* Добавлена поддержка файлов CHM!
* Добавлена поддержка закладок! Вы можете иметь столько закладок, сколько хотите, во всех документах. Вы можете переходить к ним вперёд и назад с помощью b и shift+b, устанавливать одну с помощью control+shift+b, и открывать диалог для перехода к конкретной закладке с помощью control+b.
* Добавлен установщик наряду с переносимым zip файлом! Установщик установит Paperback в каталог Program Files и автоматически установит связи файлов для вас.
* Текстовые файлы с BOM теперь должны декодироваться должным образом, и BOM больше не будет отображаться в начале текста.
* Добавлена гораздо более полная информация в строку состояния. Теперь она будет показывать вашу текущую строку, символ и процент чтения.
* Комментарии HTML, а также содержимое тегов script и style больше не будут отображаться в выходном тексте.
* При передаче относительного пути Paperback в командной строке он теперь будет правильно разрешен.
* Навигация по процентам теперь обрабатывается собственным диалогом на основе ползунка, доступным с control+shift+g.
* Документы без известных заголовков или авторов теперь будут иметь значение по умолчанию.
* Логика сохранения позиции теперь гораздо умнее и должна только писать на диск при абсолютной необходимости.
* Документ, на котором вы сосредоточились при закрытии Paperback, теперь запомнен при перезагрузке приложения.
* Входные данные в диалоги go to line и go to page теперь должны быть более строго дезинфицированы.
* Исправлена навигация таблицы содержания в книгах epub 3 с относительными путями в их манифестах.
