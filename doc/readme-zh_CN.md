# 平装本 - 版本 0.8.5 {#paperback---version-0.8.5}

## 简介 {#introduction}

Paperback 是一款轻量、快速且易于使用的电子书和文档
阅读器，适合从普通读者到资深用户的各类人群。它
专为屏幕阅读器无障碍支持、高速运行以及清爽无冗余的 使用体验而设计。

## 系统要求 {#system-requirements}

Paperback 目前支持 Windows、macOS、iOS 和 Android 系统。

## 功能 {#features}

-   完全独立运行，无需在 计算机上安装任何软件即可开始阅读。
-   运行速度极快，即使在老旧硬件上也是如此。
-   简洁的标签页界面，支持并排打开任意数量的 文档。
-   会保存您在每个已打开文档中的 精确阅读位置。
-   可选功能：记住您关闭程序时已打开的文档，并在下次启动时
    恢复这些文档。
-   包含与许多屏幕阅读器网页浏览模式 类似的导航功能，可快速轻松地在
    文档中导航。
-   包含功能强大的查找对话框，支持历史记录 和正则表达式等功能。
-   既可完全便携式运行，也可安装并自动设置 文件关联。
-   支持大量常见的文件格式。

## 屏幕阅读器兼容性 {#screen-reader-compatibility}

Paperback 与所有主流屏幕阅读器均兼容良好。不过， 对于 JAWS
用户存在一个已知问题。

### JAWS 与盲文显示器 {#jaws-and-braille-displays}

如果您将 JAWS 与盲文显示器配合使用，可能会发现当使用显示器的
导航键向前滚动时，长 段落会被截断。"阅读当前段落"命令也会受到影响。 这是
JAWS 在处理 RICHEDIT50W 文本控件时出现的一个错误，并非 Paperback
自身的问题，而且鉴于 Vispero 对响应开源软件问题的
积极态度，该问题的修复方案却花了相当长的时间 才得以推出。

经过数月的等待，最终通过 JAWS 讨论组 公布了以下解决方法：编辑
`paperback.jcf` 并将 "盲文呈现与平移"设置为"如有可用，始终使用 DOM"。
你还需要启用"按段落平移文本"，否则你的
显示器将停留在当前段落，而不会继续前进。在
这两项设置都启用后，平移功能应该就能正常工作了。

## 当前支持的文件 类型 {#currently-supported-file-types}

Paperback 支持以下格式和扩展名：

-   CHM 帮助文件（`.chm`)
-   DAISY电子书（`.opf`, `.zip`)
-   EPUB 电子书 (`.epub`)
-   FB2 电子书 (`.fb2`)
-   HTML文档 (`.htm`, `.html`, `.xhtml`)
-   Markdown 文档 (`.md`, `.markdown`, `.mdx`, `.mdown`, `.mdwn`,
    `.mkd`, `.mkdn`, `.mkdown`, `.ronn`)
-   Microsoft Word文档 (`.docx`, `.docm`, `.doc`)
-   MOBI/Kindle电子书 (`.mobi`, `.azw`, `.azw3`)
-   OpenDocument演示文稿 (`.odp`, `.fodp`)
-   OpenDocument 文本文档 (`.odt`, `.fodt`)
-   PDF文档 (`.pdf`)
-   PowerPoint演示文稿 (`.pptx`, `.pptm`, `.ppt`)
-   RTF文档 (`.rtf`)
-   纯文本和日志文件 (`.txt`, `.log`)

## 键盘快捷键 {#keyboard-shortcuts}

Paperback 专为优先使用键盘而设计。以下是当前的 快捷键。

以下快捷键适用于 Windows 系统。若 macOS 系统存在差异，则会在括号中注明
对应的快捷键------主要是因为 Ctrl+G、Ctrl+W 以及
Alt+左/右方向键在该平台上已被其他系统或应用程序的约定 占用。

### "文件"菜单 {#file-menu}

-   `Ctrl+O`：打开文档。
-   `Ctrl+F4` (macOS： `Cmd+W`)：关闭当前 文档。
-   `Ctrl+Shift+F4` (macOS: `Cmd+Shift+W`): 关闭 所有已打开的文档。
-   `Ctrl+Shift+T`：重新打开上一个关闭的文档。
-   `Ctrl+R`: 显示"所有文档"对话框（从"最近 使用的文档"中）。
-   `Ctrl+Q`: 退出（仅限 Windows；在 macOS 上，此选项位于
    应用程序菜单中）。

### "前往"菜单 {#go-menu}

-   `Ctrl+F`: 显示"查找"对话框。
-   `F3` (macOS： `Cmd+G`）：查找下一个。
-   `Shift+F3` (macOS： `Cmd+Shift+G`): 查找 上一个。
-   `Ctrl+G` (macOS: `Cmd+L`): 转到行。
-   `Ctrl+Shift+G` (macOS: `Cmd+Shift+L`): 跳转至 百分比。
-   `Ctrl+P`: 转到页面（当当前 文档支持时）。
-   `Alt+Left` (macOS: `Cmd+[`): 在 导航历史记录中返回。
-   `Alt+Right` (macOS: `Cmd+]`): 在 导航历史记录中向前跳转。
-   `[`: 上一节。
-   `]`: 下一节。
-   `Shift+H`: 上一个标题。
-   `H`: 下一标题。
-   `Shift+1` 通过 `Shift+6`: 上一级标题 （级别1-6）。
-   `1` 通过 `6`: 下一级标题（级别 1-6）。
-   `Shift+P`: 上一页。
-   `P`: 下一页。
-   `Shift+B`: 上一个书签。
-   `B`: 下一个书签。
-   `Shift+N`: 上一条笔记。
-   `N`: 下一条笔记。
-   `Ctrl+B`: 跳转至所有书签和笔记。
-   `Ctrl+Alt+B`: 仅跳转至书签。
-   `Ctrl+Alt+M`: 仅跳转至笔记。
-   `Ctrl+Shift+W` (macOS： `RawCtrl+Shift+W`, 即物理上的 Control
    键，而非 Cmd 键)：查看当前位置的 笔记正文。
-   `Shift+K`: 上一个链接。
-   `K`: 下一个链接。
-   `Shift+G`: 上一张图片。
-   `G`: 下一张图片。
-   `Shift+F`: 上一个图。
-   `F`: 下一幅图。
-   `Shift+T`: 上一个表格。
-   `T`: 下一张表格。
-   `Shift+S`: 上一分隔符。
-   `S`: 下一个分隔符。
-   `Shift+L`: 上一个列表。
-   `L`: 下一个列表。
-   `Shift+I`: 上一个列表项。
-   `I`: 下一个列表项。
-   `Shift+,`: 跳转到当前容器（列表 或表格）的开头。
-   `,`: 跳过当前容器（列表或 表格）的末尾。

### "工具"菜单 {#tools-menu}

-   `Ctrl+W` （macOS： `RawCtrl+W`，即 物理上的 Control 键而非 Cmd
    键）：显示当前 文档的字数统计。
-   `Ctrl+I`: 显示文档信息。
-   `Ctrl+T`: 显示目录。
-   `F7`: 显示元素列表。
-   `Ctrl+Shift+C`: 打开包含该文档的文件夹。
-   `Ctrl+Shift+V`: 在 Web 视图中打开当前内容。
-   `Ctrl+U`: 在新标签页中查看文档源代码。
-   `Ctrl+Shift+E`: 导出文档数据 (`.paperback`).
-   `Ctrl+Shift+I`: 导入文档数据 (`.paperback`).
-   `Ctrl+E`: 将当前文档导出为纯文本。
-   `Ctrl+Shift+B`: 在当前 选中位置/光标处添加或移除书签。
-   `Ctrl+Shift+N`: 在当前 选定位置/光标处添加或编辑书签注释。
-   `Ctrl+Alt+W`: 切换自动换行。
-   `Ctrl+,`: 打开选项（macOS：首选项，位于应用 菜单下）。
-   `Ctrl+Shift+S`: 切换休眠定时器。

### "帮助"菜单 {#help-menu}

-   `Ctrl+F1`: 显示"关于"对话框。
-   `F1`: 在默认浏览器中查看帮助。
-   `Shift+F1`: 在 Paperback 中查看帮助。
-   `Ctrl+Shift+U`: 检查更新。
-   `Ctrl+D`: 在默认 浏览器中打开捐赠页面。

### 其他文档查看 快捷键 {#additional-document-view-keys}

-   `Delete` / `Numpad Delete` ： 关闭所选文档标签页。
-   `Enter` 或 `Space` 在文档文本中：
    激活光标所在位置的链接，或在光标位于表格 标记上时打开表格视图。
-   `Shift+F10` 或在文档 文本中使用"菜单/应用程序"键：打开上下文菜单。
