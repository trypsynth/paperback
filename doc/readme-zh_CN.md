# Paperback - 版本 0.9.0

## 简介

Paperback 是一款轻量、快速且无障碍的电子书与文档阅读器，适合所有人使用，从普通读者到重度高级用户。它专为屏幕阅读器无障碍性、高速运行和无冗余的体验而设计。

## 系统要求

Paperback 目前可运行于 Windows 10/11 以及所有现代版本的 ARM macOS。原生 iOS 和 Android 应用正在积极开发中，计划在 0.9.0 桌面版发布后不久推出公开测试版本，随后将发布覆盖全部四个平台的统一 1.0 版本。

## 功能特性

* 完全独立运行，无需在您的计算机上安装任何软件即可开始阅读。
* 速度极快，即使在老旧硬件上也是如此。
* 简洁的标签式界面，让您可以同时并排打开任意数量的文档。
* 保存您在打开的每个文档中的精确阅读位置。
* 可选择记住您关闭程序时打开的文档，并在下次启动时恢复它们。
* 包含与许多屏幕阅读器的网页浏览模式类似的导航功能，可快速轻松地浏览文档。
* 包含功能强大的查找对话框，支持历史记录和正则表达式等功能。
* 可完全便携运行，也可安装并自动设置文件关联。
* 支持大量常见文件格式。

## 屏幕阅读器兼容性

Paperback 与所有主流屏幕阅读器都能良好配合。不过，JAWS 用户存在一个已知问题。

### JAWS 与盲文显示器

如果您将 JAWS 与盲文显示器搭配使用，可能会发现使用显示器的导航键向前滚动时，长段落会被截断。朗读当前段落命令同样受到影响。这是 JAWS 处理 RICHEDIT50W 文本控件时的一个缺陷，而非 Paperback 本身的问题；考虑到 Vispero 对回应开源软件相关问题的“热情”，这个修复方法花了相当长的时间才浮出水面。

经过数月等待，最终通过 JAWS 讨论组找到的解决办法是：编辑 `paperback.jcf`，将“Braille Presentation and Panning”设置为“Always use DOM if available”。您还需要启用“Pan Text by Paragraph”，否则您的显示器会停留在当前段落而不会向前推进。两项设置都到位后，滚动应该就能正常工作了。

## 目前支持的文件类型

Paperback 支持以下格式和扩展名：

* CHM 帮助文件（`.chm`）
* DAISY 图书（`.opf`、`.zip`）
* EPUB 图书（`.epub`）
* FB2 电子书（`.fb2`）
* HTML 文档（`.htm`、`.html`、`.xhtml`）
* Markdown 文档（`.md`、`.markdown`、`.mdx`、`.mdown`、`.mdwn`、`.mkd`、`.mkdn`、`.mkdown`、`.ronn`）
* Microsoft Word 文档（`.docx`、`.docm`、`.doc`）
* MOBI/Kindle 图书（`.mobi`、`.azw`、`.azw3`）
* OpenDocument 演示文稿（`.odp`、`.fodp`）
* OpenDocument 文本文件（`.odt`、`.fodt`）
* PDF 文档（`.pdf`）
* PowerPoint 演示文稿（`.pptx`、`.pptm`、`.ppt`）
* RTF 文档（`.rtf`）
* 纯文本和日志文件（`.txt`、`.log`）

## 键盘快捷键

Paperback 以键盘优先的方式设计。以下是当前的快捷键。

下面的快捷键适用于 Windows。若 macOS 有所不同，会在括号中注明等效按键——主要是因为 Ctrl+G、Ctrl+W 和 Alt+Left/Right 在该平台上已被其他系统或应用惯例占用。

### 文件菜单

* `Ctrl+O`：打开文档。
* `Ctrl+F4`（macOS：`Cmd+W`）：关闭当前文档。
* `Ctrl+Shift+F4`（macOS：`Cmd+Shift+W`）：关闭所有已打开的文档。
* `Ctrl+Shift+T`：重新打开最后关闭的文档。
* `Ctrl+R`：显示“所有文档”对话框（来自最近文档）。
* `Ctrl+Q`：退出（仅限 Windows；在 macOS 上位于应用菜单中）。

### 转到菜单

* `Ctrl+F`：显示查找对话框。
* `F3`（macOS：`Cmd+G`）：查找下一个。
* `Shift+F3`（macOS：`Cmd+Shift+G`）：查找上一个。
* `Ctrl+G`（macOS：`Cmd+L`）：转到行。
* `Ctrl+Shift+G`（macOS：`Cmd+Shift+L`）：转到百分比。
* `Ctrl+P`：转到页面（当前文档支持时）。
* `=`：播报当前阅读百分比。
* `Alt+Left`（macOS：`Cmd+[`）：在导航历史中后退。
* `Alt+Right`（macOS：`Cmd+]`）：在导航历史中前进。
* `[`：上一节。
* `]`：下一节。
* `Shift+H`：上一个标题。
* `H`：下一个标题。
* `Shift+1` 至 `Shift+6`：上一个 1-6 级标题。
* `1` 至 `6`：下一个 1-6 级标题。
* `Shift+P`：上一页。
* `P`：下一页。
* `Shift+B`：上一个书签。
* `B`：下一个书签。
* `/`：设置临时书签。
* `\`：跳转到临时书签。
* `Shift+N`：上一条笔记。
* `N`：下一条笔记。
* `Ctrl+B`：跳转到所有书签和笔记。
* `Ctrl+Alt+B`：仅跳转到书签。
* `Ctrl+Alt+M`：仅跳转到笔记。
* `Ctrl+Shift+W`（macOS：`RawCtrl+Shift+W`，即物理 Control 键而非 Cmd）：查看当前位置的笔记文本。
* `Shift+K`：上一个链接。
* `K`：下一个链接。
* `Shift+G`：上一张图片。
* `G`：下一张图片。
* `Shift+F`：上一个图表。
* `F`：下一个图表。
* `Shift+T`：上一个表格。
* `T`：下一个表格。
* `Shift+S`：上一个分隔符。
* `S`：下一个分隔符。
* `Shift+L`：上一个列表。
* `L`：下一个列表。
* `Shift+I`：上一个列表项。
* `I`：下一个列表项。
* `Shift+,`：转到当前容器（列表或表格）的开头。
* `,`：转到当前容器（列表或表格）的末尾之后。

### 工具菜单

* `Ctrl+W`（macOS：`RawCtrl+W`，即物理 Control 键而非 Cmd）：显示当前文档的字数统计。
* `Ctrl+I`：显示文档信息。
* `Ctrl+T`：显示目录。
* `F7`：显示元素列表。
* `Ctrl+Shift+C`：打开所在文件夹。
* `Ctrl+Shift+V`：在 Web 视图中打开当前内容。
* `Ctrl+U`：在新标签页中查看文档源代码。
* `Ctrl+Shift+E`：导出文档数据（`.paperback`）。
* `Ctrl+Shift+I`：导入文档数据（`.paperback`）。
* `Ctrl+E`：将当前文档导出为纯文本。
* `Ctrl+Shift+B`：在当前选区/光标处切换书签。
* `Ctrl+Shift+N`：在当前选区/光标处添加或编辑书签笔记。
* `Ctrl+Alt+W`：切换自动换行。
* `Ctrl+Space`：播放/暂停音频朗读。
* `'`：音频朗读向前跳转。
* `;`：音频朗读向后跳转。
* `Ctrl+'`：增加音频跳转幅度。
* `Ctrl+;`：减少音频跳转幅度。
* `F11`（macOS：`RawCtrl+Ctrl+F`，即 Control+Command+F）：切换全屏。
* `Ctrl+,`：打开选项（macOS：偏好设置，位于应用菜单中）。
* `Ctrl+Shift+S`：切换睡眠定时器。

### 帮助菜单

* `Ctrl+F1`：显示关于对话框。
* `F1`：在默认浏览器中查看帮助。
* `Shift+F1`：在 Paperback 中查看帮助。
* `Ctrl+Shift+U`：检查更新。
* `Ctrl+D`：在默认浏览器中打开捐赠页面。

### 其他文档视图按键

* 在标签控件上按 `Delete` / `Numpad Delete`：关闭选中的文档标签页。
* 在文档文本中按 `Enter` 或 `Space`：激活光标处的链接，或在表格标记处打开表格视图。
* 在文档文本中按 `Shift+F10` 或菜单/应用程序键：打开上下文菜单。

### 版本 0.9.0

#### 新增

##### 常规

* 文档文本现已分页处理，这意味着你现在只需几秒钟就能加载包含数千万字的书籍。若发现任何异常，请反馈。

##### 平台支持
* 支持 ARM64 Windows！
* 原生 macOS 支持！

##### 所有文档对话框
* 一个“定位”按钮，用于定位刚刚更改路径的丢失书籍。
* 状态筛选器和状态栏，可按文档状态筛选，并查看显示和选中了多少文档。

    * 背景颜色；

    * 段间距；

##### 书签
