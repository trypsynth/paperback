简介

Paperback 是一款轻量、快速且无障碍的电子书、文档和有声书阅读器，适合从普通读者到重度高级用户的各类人群。它专为屏幕阅读器无障碍访问、高速运行以及无臃肿体验而设计。

系统要求

Paperback 可在 Windows 10/11、所有现代版本的 ARM macOS、Linux、iOS 17 及更高版本，以及 Android 7 及更高版本上运行。iOS 和 Android 应用已在 App Store 和 Google Play 上架。

功能

  • 完全独立运行，无需在计算机上安装任何其他软件即可开始阅读。
  • 速度极快，即使在老旧硬件上也能流畅运行。
  • 简洁的选项卡式界面，允许您并排打开任意数量的文档。
  • 为您打开的每个文档保存精确的阅读位置。
  • 可选择记住程序关闭时打开的文档，并在下次启动时恢复。
  • 包含与许多屏幕阅读器网页浏览模式类似的导航功能，可快速轻松地在文档中移动。
  • 包含强大的查找对话框，支持历史记录和正则表达式等功能。
  • 既可以完全便携运行，也可以安装并自动设置文件关联。
  • 支持大量常见文件格式。
  • 可播放有声书，支持可调速度，以及能记住精确时间的书签。
  • 使用 Windows 和 macOS 内置的 OCR 读取扫描版 PDF 页面。
  • 书签和笔记，让您可以标记位置并随时返回。
  • 每个键盘快捷键都可以更改。
  • 附带 pb，一个命令行工具，可将任何支持的文档转换为 HTML、Markdown 或纯文本。

屏幕阅读器兼容性

Paperback 可与所有主流屏幕阅读器良好配合。不过，对于 JAWS 用户存在两个已知问题。

JAWS 与盲文显示器

如果您将 JAWS 与盲文显示器配合使用，可能会发现使用显示器的导航键向前平移时长段落被截断。“朗读当前段落”命令也受到影响。这是 JAWS 处理 RICHEDIT50W 文本控件时的一个错误，并非 Paperback 本身的问题，而且鉴于 Vispero 对回应开源软件问题的积极性，找到修复方案花费了相当长的时间。

经过数月的等待，最终通过 JAWS 讨论组找到了解决办法：编辑 paperback.jcf，将“盲文显示与平移”设置为“可用时始终使用 DOM”。您还需要启用“按段落平移文本”，否则显示器会停留在当前活动段落而不会前进。完成这两项设置后，平移应该就能正常工作了。

JAWS 与 Paperback 的消息

Paperback 会说诸如“没有页面。”或“此文档没有音频。”之类的内容，作为无障碍通知，这正是让屏幕阅读器在它正在朗读的内容之上朗读这些内容的方式。JAWS 只有在为应用程序开启“启用无障碍通知事件”时才会对这些做出反应，而在某些机器上它并未开启。

如果 JAWS 在您按下本应报告某些内容的按键时什么也不说，请在 Paperback 位于前台时打开设置中心（Insert+6），搜索“notification”，然后勾选“启用无障碍通知事件”。这会将设置写入 paperback.jcf，因此它只对 Paperback 生效。

当前支持的文件类型

Paperback 支持以下格式和扩展名：

  • 漫画压缩包（.cbz）
  • CHM 帮助文件（.chm）
  • DAISY 图书（.opf、.zip）
  • EPUB 图书（.epub）
  • FB2 电子书（.fb2）
  • HTML 文档（.htm、.html、.xhtml）
  • 手册页，包括 man 和 BSD mdoc（.1 到 .9、.man、.roff，以及各自的 gzip 压缩形式）
  • Markdown 文档（.md、.markdown、.mdx、.mdown、.mdwn、.mkd、.mkdn、.mkdown、.ronn）
  • Microsoft Word 文档（.docx、.docm、.doc）
  • M4B 有声书（.m4b）
  • MOBI/Kindle 图书（.mobi、.azw、.azw3）
  • MP3 有声书（.mp3）
  • OpenDocument 演示文稿（.odp、.fodp）
  • OpenDocument 文本文件（.odt、.fodt）
  • PDF 文档（.pdf）
  • PowerPoint 演示文稿（.pptx、.pptm、.ppt）
  • reStructuredText 文档（.rst、.rest）
  • RTF 文档（.rtf）
  • Windows Write 文档（.wri）
  • WinHelp 文件（.hlp）
  • 纯文本和日志文件（.txt、.log）

键盘快捷键

Paperback 专为键盘优先使用而设计。以下是当前的快捷键。

以下快捷键适用于 Windows。若 macOS 有所不同，将在括号中注明等效按键——主要是因为在该平台上 Ctrl+G、Ctrl+W 以及 Alt+左/右箭头已被其他系统或应用约定占用。

文件菜单

  • Ctrl+O：打开文档。
  • Ctrl+F4（macOS：Cmd+W）：关闭当前文档。
  • Ctrl+Shift+F4（macOS：Cmd+Shift+W）：关闭所有打开的文档。
  • Ctrl+Shift+T：重新打开上次关闭的文档。
  • Ctrl+R：显示“所有文档”对话框（来自“最近文档”）。
  • Ctrl+Q：退出（仅限 Windows；在 macOS 上此功能位于应用菜单下）。

转到菜单

  • Ctrl+F：显示查找对话框。
  • F3（macOS：Cmd+G）：查找下一个。
  • Shift+F3（macOS：Cmd+Shift+G）：查找上一个。
  • Ctrl+G（macOS：Cmd+L）：转到行。
  • Ctrl+Shift+G（macOS：Cmd+Shift+L）：转到百分比。
  • Ctrl+P：转到页（当当前文档支持时）。
  • =：朗读当前阅读百分比和页码，例如“15%，第 30 页”。对于没有页码的文档，将省略页码。
  • Alt+Left（macOS：Cmd+[）：后退导航历史。
  • Alt+Right（macOS：Cmd+]）：前进导航历史。
  • [：上一章节。
  • ]：下一章节。
  • Shift+H：上一个标题。
  • H：下一个标题。
  • Shift+1 至 Shift+6：上一个 1-6 级标题。
  • 1 至 6：下一个 1-6 级标题。
  • Shift+P：上一页。
  • P：下一页。
  • Shift+B：上一个书签。
  • B：下一个书签。
  • /：设置临时书签。
  • \：跳转到临时书签。
  • Shift+N：上一个笔记。
  • N：下一个笔记。
  • Ctrl+B：跳转到所有书签和笔记。
  • Ctrl+Alt+B：仅跳转到书签。
  • Ctrl+Alt+M：仅跳转到笔记。
  • Ctrl+Shift+W（macOS：RawCtrl+Shift+W，即物理 Control 键而非 Cmd）：查看当前位置的笔记文本。
  • Shift+K：上一个链接。
  • K：下一个链接。
  • Shift+G：上一张图片。
  • G：下一张图片。
  • Shift+F：上一个图形。
  • F：下一个图形。
  • Shift+T：上一个表格。
  • T：下一个表格。
  • Shift+M：上一个公式。
  • M：下一个公式。
  • Shift+S：上一个分隔符。
  • S：下一个分隔符。
  • Shift+L：上一个列表。
  • L：下一个列表。
  • Shift+I：上一个列表项。
  • I：下一个列表项。
  • Shift+,：转到当前容器（列表或表格）的开头。
  • ,：越过当前容器（列表或表格）的末尾。

工具菜单

  • Ctrl+W（macOS：RawCtrl+W，即物理 Control 键而非 Cmd）：显示当前文档的字数统计。
  • Ctrl+I：显示文档信息。
  • Ctrl+T：显示目录。
  • F7：显示元素列表。
  • Ctrl+Shift+C：打开所在文件夹。
  • Ctrl+Shift+V：在 Web 视图中打开当前内容。
  • Ctrl+U：在新标签页中查看文档源。
  • Ctrl+Shift+E：导出文档数据（.paperback）。
  • Ctrl+Shift+I：导入文档数据（.paperback）。
  • Ctrl+E：将当前文档导出为纯文本。
  • Ctrl+Shift+B：在当前选择/光标处切换书签。
  • Ctrl+Shift+N：在当前选择/光标处添加或编辑书签笔记。
  • Ctrl+Alt+W：切换自动换行。
  • Ctrl+Space（macOS：RawCtrl+Space，即物理 Control 键，因为 Cmd+Space 会打开 Spotlight）：播放/暂停音频朗读。
  • '：音频朗读向前跳转。
  • ;：音频朗读向后跳转。
  • Shift+'：增大音频跳转步长。
  • Shift+;：减小音频跳转步长。
  • Ctrl+Shift+.：加快音频朗读速度。
  • Ctrl+Shift+,：减慢音频朗读速度。
  • F11（macOS：RawCtrl+Ctrl+F，即 Control+Command+F）：切换全屏。
  • Ctrl+,：打开设置（macOS：位于应用菜单下）。
  • Ctrl+Shift+S：切换睡眠定时器。
  • Ctrl+Shift+O：使用 OCR 识别扫描版 PDF 的页面范围。
  • Alt+F9（macOS：Cmd+F9）：标记选区起点，这样从这里到您到达的任何位置之间的所有内容都可以一次性复制。
  • Alt+F10（macOS：Cmd+F10）：将从标记的选区起点到当前位置的所有内容复制到剪贴板。
  • Alt+Shift+F9（macOS：Cmd+Shift+F9）：跳回标记的选区起点，并保留标记。

帮助菜单

  • Ctrl+F1：显示关于对话框。
  • F1：在默认浏览器中查看帮助。
  • Shift+F1：在 Paperback 中查看帮助。
  • Ctrl+Shift+U：检查更新。
  • Ctrl+D：在默认浏览器中打开捐赠页面。

文档视图附加按键

  • 选项卡控件上的 Delete / 数字键盘 Delete：关闭选中的文档选项卡。
  • 文档文本中的 Enter 或 Space：跟随光标处的链接，或打开表格或公式视图。
  • 扫描版 PDF 页面上的 Enter：使用 OCR 识别该页。
  • 文档文本中的 Shift+F10 或菜单/应用程序键：打开上下文菜单。

iOS 和 Android

iOS 和 Android 应用使用与桌面版相同的阅读引擎，因此它们打开相同的格式，并以相同的方式记住您的位置。它们专为在 iOS 上配合 VoiceOver、在 Android 上配合 TalkBack 使用而构建。

打开文档

  • 使用“打开图书”按钮，或从“文件”应用或其他应用打开文档并选择 Paperback。
  • 在 Android 上，您可以在“设置”中改为开启应用内文件浏览器。它需要“所有文件访问”权限，并且会直接打开大文件，而不是先复制它们。
  • 长按“打开图书”按钮可导入或导出文档数据（.paperback），与桌面应用使用的文件相同。

阅读和收听

每个应用都有两种阅读文档的方式。在文本模式下，您使用屏幕阅读器阅读文本。在朗读模式下，Paperback 使用您在“设置”中选择的语音为您朗读文本，并在后台和锁屏界面继续播放。通过“更多选项”菜单在两者之间切换。

有声书，如 DAISY、M4B 和 MP3 图书，则播放它们自己的录音。

阅读栏

屏幕底部的栏从左到右依次为：

  • 导航单位，例如段落、标题、页面或链接。在其上向上或向下滑动可更改。
  • 上一个、播放和下一个按钮。上一个和下一个按导航单位移动。
  • 语音速率。在其上向上或向下滑动可更改 Paperback 的朗读速度。

您也可以在播放按钮上向上或向下滑动，以按导航单位移动，而无需去按上一个和下一个按钮。如果您只用这种方式，设置中的“隐藏上一个和下一个按钮”会将它们从屏幕阅读器的路径中移除。“向上滑动向前移动”设置决定滑动方向。

更多选项

“更多选项”菜单包含其他所有功能。某些项目在每个应用上的工作方式略有不同。

  • 切换到 TTS 模式或切换到文本模式： 在朗读模式和文本模式之间切换，如上所述。在文本模式下，“朗读”项目可在不离开文本模式的情况下开始和暂停朗读。
  • 目录： 图书的章节，打开时位于您正在阅读的章节。选择一个可直接跳转到该章节。带有子章节的条目可以使用屏幕阅读器的操作展开和折叠。
  • 元素： 文档标题或链接的列表。在 iOS 上使用“类型”选择器，在 Android 上使用选项卡，在两者之间切换，然后选择一个跳转到它。
  • 查找： 输入要查找的内容，或从搜索历史中选择较早的搜索，并选择是否区分大小写、仅匹配全字或使用正则表达式。查找上一个和查找下一个会跳转到匹配项并朗读其位置，查找对话框保持打开，以便您可以继续。在朗读模式下，查找也会作为阅读栏上的导航单位显示，因此您也可以从那里逐步浏览匹配项。
  • 转到： 跳转到文档中的某一行、某一页或某个百分比。使用“模式”选择器选择。
  • 最近文档： 您打开过的每个文档，每个都标记为当前已打开、已关闭或文件缺失。每个都有两个屏幕阅读器操作：“移除”将其从列表中删除，“定位”让您找到文件已移动的文档。“清除最近文档”会清空列表而不删除任何文档。
  • 字数统计： 文档中的单词数。
  • 文档信息： 标题、作者、文件名，在 iOS 上还包括行数和字符数。
  • 导出： 将文档保存为纯文本、HTML 或 Markdown。
  • 睡眠定时器： 在 5、10、15、30、45 或 60 分钟后停止阅读，或使用您自己的时间。运行时再次打开可查看剩余时间或取消。
  • 帮助： 打开此 readme。
  • 设置：
    • 文字转语音： 语音、语音速率和音高，一个“播放示例”按钮用于试听，以及段落之间的暂停。Android 还允许您选择语音引擎。在 iOS 上，这里也是语音词典的位置：改变单词发音方式的规则，可应用于所有语音或部分语音。
    • 可读性： 文本大小、行距、段落间距、对齐方式和高对比度文本。iOS 还有浅色和深色外观。
    • 行为： 应用启动时是否重新打开文档，播放按钮上的滑动方向，以及是否隐藏上一个和下一个按钮。Android 这里还有应用内文件浏览器。

键盘和耳机

使用键盘时，桌面版的打开图书、最近文档、查找、转到、目录、字数统计、文档信息、导出和睡眠定时器的快捷键都可用，在 iOS 上使用 Cmd 代替 Ctrl。用于按标题、页面、链接等移动的单字母键也一样，Space 可播放和暂停。在 iOS 上，只有当 VoiceOver 的单字母快速导航关闭时，单字母键才会到达 Paperback。

在 Android 上，耳机按钮按一次播放/暂停，按两次向前移动，按三次向后移动。

更新日志

版本 1.0

1.0 是首个在全部五个平台——Windows、macOS、Linux、iOS 和 Android——上发布的版本，其中 iOS 和 Android 应用已在 App Store 和 Google Play 上架。

新增

常规

  • Linux 支持，以 AppImage 或 tar.gz 形式提供，并具有桌面集成，因此文档可以从文件管理器中打开。
  • 使用 Alt+F9 标记选区起点，使用 Alt+F10 将从那里到您到达位置的所有内容复制，使用 Alt+Shift+F9 跳回标记处，从而无需用 Shift+方向键选取即可复制长段文本。这三项都在“工具 > 选择并复制”下。
  • = 快捷键现在除了百分比还会朗读页码，例如“15%，第 30 页”，对于没有页码的文档保持不变。
  • 关于对话框现在显示 Paperback 的许可证和所有翻译者。
  • 乌克兰语翻译。

新格式

  • 漫画压缩包（.cbz）。
  • M4B 有声书，按章节分割。
  • 手册页，包括 man 和 BSD mdoc，无论是否 gzip 压缩。
  • MP3 有声书，当文件包含章节时按章节分割。
  • reStructuredText 文档。
  • Windows Write（.wri）文件。
  • WinHelp（.hlp）文件。
  • Word 6 和 Word 95 文档。

OCR
