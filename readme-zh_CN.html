简介

Paperback 是一款轻量、快速且无障碍的电子书和文档阅读器，适合从普通读者到重度高级用户的各类人群。它专为屏幕阅读器无障碍访问、高速运行以及无臃肿体验而设计。

系统要求

Paperback 目前可在 Windows 10/11 以及所有现代版本的 ARM macOS 上运行。原生 iOS 和 Android 应用正在积极开发中，公共测试版本计划在 0.9.0 桌面版发布后不久推出，最终将实现覆盖四个平台的统一 1.0 版本。

功能

  • 完全独立运行，无需在计算机上安装任何其他软件即可开始阅读。
  • 速度极快，即使在老旧硬件上也能流畅运行。
  • 简洁的选项卡式界面，允许您并排打开任意数量的文档。
  • 为您打开的每个文档保存精确的阅读位置。
  • 可选择记住程序关闭时打开的文档，并在下次启动时恢复。
  • 包含与许多屏幕阅读器网页浏览模式类似的导航功能，可快速轻松地在文档中移动。
  • 包含强大的查找对话框，支持历史记录和正则表达式等功能。
  • 既可以完全便携运行，也可以安装并自动设置文件关联。
  • 支持大量常见文件格式。

屏幕阅读器兼容性

Paperback 可与所有主流屏幕阅读器良好配合。不过，对于 JAWS 用户存在一个已知问题。

JAWS 与盲文显示器

如果您将 JAWS 与盲文显示器配合使用，可能会发现使用显示器的导航键向前平移时长段落被截断。“朗读当前段落”命令也受到影响。这是 JAWS 处理 RICHEDIT50W 文本控件时的一个错误，并非 Paperback 本身的问题，而且鉴于 Vispero 对回应开源软件问题的积极性，找到修复方案花费了相当长的时间。

经过数月的等待，最终通过 JAWS 讨论组找到了解决办法：编辑 paperback.jcf，将“盲文显示与平移”设置为“可用时始终使用 DOM”。您还需要启用“按段落平移文本”，否则显示器会停留在当前活动段落而不会前进。完成这两项设置后，平移应该就能正常工作了。

当前支持的文件类型

Paperback 支持以下格式和扩展名：

  • CHM 帮助文件（.chm）
  • DAISY 图书（.opf、.zip）
  • EPUB 图书（.epub）
  • FB2 电子书（.fb2）
  • HTML 文档（.htm、.html、.xhtml）
  • Markdown 文档（.md、.markdown、.mdx、.mdown、.mdwn、.mkd、.mkdn、.mkdown、.ronn）
  • Microsoft Word 文档（.docx、.docm、.doc）
  • MOBI/Kindle 图书（.mobi、.azw、.azw3）
  • OpenDocument 演示文稿（.odp、.fodp）
  • OpenDocument 文本文件（.odt、.fodt）
  • PDF 文档（.pdf）
  • PowerPoint 演示文稿（.pptx、.pptm、.ppt）
  • RTF 文档（.rtf）
  • 纯文本和日志文件（.txt、.log）

键盘快捷键

Paperback 专为键盘优先使用而设计。以下是当前的快捷键。

以下快捷键适用于 Windows。若 macOS 有所不同，将在括号中注明等效按键——主要是因为在该平台上 Ctrl+G、Ctrl+W 以及 Alt+左/右箭头已被其他系统或应用约定占用。

文件菜单

  • Ctrl+O：打开文档。
  • Ctrl+F4（macOS：Cmd+W）：关闭当前文档。
  • Ctrl+Shift+F4（macOS：Cmd+Shift+W）：关闭所有打开的文档。
  • Ctrl+Shift+T：重新打开上次关闭的文档。
  • Ctrl+R：显示“所有文档”对话框（来自“最近文档”）。
  • Ctrl+Q：退出（仅限 Windows；在 macOS 上此功能位于应用菜单下）。

转到菜单

  • Ctrl+F：显示查找对话框。
  • F3（macOS：Cmd+G）：查找下一个。
  • Shift+F3（macOS：Cmd+Shift+G）：查找上一个。
  • Ctrl+G（macOS：Cmd+L）：转到行。
  • Ctrl+Shift+G（macOS：Cmd+Shift+L）：转到百分比。
  • Ctrl+P：转到页（当当前文档支持时）。
  • =：朗读当前阅读百分比。
  • Alt+Left（macOS：Cmd+[）：后退导航历史。
  • Alt+Right（macOS：Cmd+]）：前进导航历史。
  • [：上一章节。
  • ]：下一章节。
  • Shift+H：上一个标题。
  • H：下一个标题。
  • Shift+1 至 Shift+6：上一个 1-6 级标题。
  • 1 至 6：下一个 1-6 级标题。
  • Shift+P：上一页。
  • P：下一页。
  • Shift+B：上一个书签。
  • B：下一个书签。
  • /：设置临时书签。
  • \：跳转到临时书签。
  • Shift+N：上一个笔记。
  • N：下一个笔记。
  • Ctrl+B：跳转到所有书签和笔记。
  • Ctrl+Alt+B：仅跳转到书签。
  • Ctrl+Alt+M：仅跳转到笔记。
  • Ctrl+Shift+W（macOS：RawCtrl+Shift+W，即物理 Control 键而非 Cmd）：查看当前位置的笔记文本。
  • Shift+K：上一个链接。
  • K：下一个链接。
  • Shift+G：上一张图片。
  • G：下一张图片。
  • Shift+F：上一个图形。
  • F：下一个图形。
  • Shift+T：上一个表格。
  • T：下一个表格。
  • Shift+S：上一个分隔符。
  • S：下一个分隔符。
  • Shift+L：上一个列表。
  • L：下一个列表。
  • Shift+I：上一个列表项。
  • I：下一个列表项。
  • Shift+,：转到当前容器（列表或表格）的开头。
  • ,：越过当前容器（列表或表格）的末尾。

工具菜单

  • Ctrl+W（macOS：RawCtrl+W，即物理 Control 键而非 Cmd）：显示当前文档的字数统计。
  • Ctrl+I：显示文档信息。
  • Ctrl+T：显示目录。
  • F7：显示元素列表。
  • Ctrl+Shift+C：打开所在文件夹。
  • Ctrl+Shift+V：在 Web 视图中打开当前内容。
  • Ctrl+U：在新标签页中查看文档源。
  • Ctrl+Shift+E：导出文档数据（.paperback）。
  • Ctrl+Shift+I：导入文档数据（.paperback）。
  • Ctrl+E：将当前文档导出为纯文本。
  • Ctrl+Shift+B：在当前选择/光标处切换书签。
  • Ctrl+Shift+N：在当前选择/光标处添加或编辑书签笔记。
  • Ctrl+Alt+W：切换自动换行。
  • Ctrl+Space：播放/暂停音频朗读。
  • '：音频朗读向前跳转。
  • ;：音频朗读向后跳转。
  • Ctrl+'：增大音频跳转步长。
  • Ctrl+;：减小音频跳转步长。
  • F11（macOS：RawCtrl+Ctrl+F，即 Control+Command+F）：切换全屏。
  • Ctrl+,：打开设置（macOS：偏好设置，位于应用菜单下）。
  • Ctrl+Shift+S：切换睡眠定时器。

帮助菜单

  • Ctrl+F1：显示关于对话框。
  • F1：在默认浏览器中查看帮助。
  • Shift+F1：在 Paperback 中查看帮助。
  • Ctrl+Shift+U：检查更新。
  • Ctrl+D：在默认浏览器中打开捐赠页面。

文档视图附加按键

  • 选项卡控件上的 Delete / 数字键盘 Delete：关闭选中的文档选项卡。
  • 文档文本中的 Enter 或 Space：激活光标处的链接，或在表格标记处打开表格视图。
  • 文档文本中的 Shift+F10 或菜单/应用程序键：打开上下文菜单。

更新日志

版本 0.9.1

  • 书签和笔记声音现在可在 macOS 上播放。
  • DAISY 图书现在可在 macOS 上播放音频，而不是在静音状态下打开并跟踪其时间轴。
  • 修复了 RTF 文档中弯引号、长破折号及类似字符消失，导致周围单词连在一起的问题。
  • 修复了 RTF 图片将其原始数据作为乱码文本泄漏到文档中的问题。
  • 修复了“最近文档”子菜单保留过期条目直到其他操作触发重建的问题。
  • 键盘加速键重新出现在所有翻译中，因此俄语菜单再次拥有键盘访问功能。
  • 大型 CHM 文档的打开速度现在最多可提升七倍。
  • 打开的文档现在会注册到 Windows 中，因此它们会显示在任务栏跳转列表和开始菜单的最近列表中。
  • “选项”已更名为“设置”，与移动应用以及 macOS 上的平台惯例保持一致。
  • Paperback 现在会记住运行之间的窗口位置、大小和最大化状态。
  • 复数形式现已翻译，因此计数类消息在需要多种复数形式的语言中能正确显示。
  • 选择 DAISY 图书的 ncc.html 现在会打开完整的音频书，而不仅仅是其文本。
  • “自定义键盘快捷键”对话框中的操作名称现在可以翻译。
  • 文档标题现在位于标题栏的最前面，以便在任务栏和 Alt+Tab 中区分打开的书籍。
  • 更新对话框现已翻译。

版本 0.9.0

新增

常规

  • 一个名为 pb 的命令行工具，可快速将 Paperback 支持的任何格式转换为 HTML、Markdown 或纯文本。
  • 一个选项，用于重新加载已被其他程序在磁盘上修改的文档。
  • 查看源代码选项，可在新标签页中打开文档源，例如对编辑 Markdown 很有用。
  • 文档文本现在进行了分页，这意味着您现在可以在几秒钟内加载数千万字的书籍。如果发现任何异常，请报告。

平台支持

  • ARM64 Windows 支持！
  • 原生 macOS 支持！
  • 全屏切换。

所有文档对话框

  • 定位按钮，用于定位仅路径发生更改的缺失书籍。
  • 状态筛选器和状态栏，您可以按文档状态筛选，并查看显示和选中的文档数量。
  • Ctrl+Shift+A 快捷键，用于取消选择所有文档。

选项与可读性

  • 一个可读性选项卡，包含以下选项：
    • 自动换行（从常规选项卡移入）；
    • 内联渲染表格（此版本新增，见下文）；
    • 字体；
    • 背景颜色；
    • 行距；
    • 段落间距；
    • 字距；
    • 文本对齐。
  • 自动换行菜单项及其热键。
  • 一个用于决定表格显示方式的开关，并统一了跨文档的表格显示方式。

导航

  • 支持按容器导航。
  • 一个选项，可在行间导航时自动将光标移至行首，类似于屏幕阅读器的浏览模式。
  • 等号快捷键，用于朗读您在文档中的当前百分比。

书签

  • 临时书签：每个文档可以有一个，并且会持久保存。使用斜杠设置，使用反斜杠跳转。

字数统计

  • 字数统计对话框中新增预计阅读时间，并允许设置阅读速度以使该指标真正有用。
  • 打开字数统计对话框时，如果有选区处于活动状态，现在会显示所选内容的字数。

键盘快捷键

  • 能够通过一个简单的对话框自定义应用中的每个键盘快捷键。
  • 一个可配置的键盘快捷键，用于从系统托盘恢复 Paperback。

语言

  • 荷兰语、芬兰语和波兰语。

导出

  • 扩展了导出菜单项，除了纯文本外，还允许导出为 HTML 和 Markdown。

更新器

  • 为更新进行中对话框添加了取消按钮。
  • 更新器现在会验证下载的文件未被篡改。

Web 视图

  • Web 视图现在会在您当前的阅读位置打开。

DAISY 图书

  • 支持 DAISY 2.0 图书。
  • 支持 DAISY 2.02 音频播放。

有声书

  • 能够播放有声书，目前支持 DAISY 音频（包括 DAISY 音频+文本）和音频文件压缩包。
  • 用于播放/暂停朗读、前后跳转以及调整跳转步长的键盘快捷键和菜单项。
  • 选项：将阅读光标同步到音频播放、设置音频跳转步长，以及选择在章节末尾继续跳转是否进入下一章。

CHM 文档

  • 支持列表、列表项、图形和图片。

PowerPoint

  • PowerPoint 文档现在支持表格。

修复

常规

  • 使用旧版 CJK 编码（如 GBK、Big5 和 Shift_JIS）的文档现在可以正确渲染，而不会显示为一堆乱码。
  • “重新打开上次关闭的文档”试图重新打开捆绑的 readme。
  • 重新启动 Paperback 后，所选选项卡未正确获得焦点。
  • Paperback 对 Windows 网络驱动器上文件的处理：按下“在文件夹中显示文件”现在可以在网络存储上正确定位文件，路径中不再包含奇怪字符。
  • .paperback 文件在文档恢复时将不再被强制加载；相反，当发现此类文件时会询问确认。
  • “打开所在文件夹”现在会在资源管理器中定位到给定文件。
  • 打开 readme 现在会遵循您选择的语言。
  • Paperback 的用户界面现在在高 DPI 显示器上正确缩放。
  • 在 Paperback 中打开帮助时，菜单现在会正确更新，焦点会移至文本控件。
  • 在 Windows 上切换到了一种更安全的 IPC 方法。
  • 切换选项卡时现在会朗读活动文档的标题。
  • 通过将内部每字符索引表的大小减半，减少了大型文档的内存使用量。

所有文档对话框

  • Esc 键无法关闭“文档信息”和“所有文档”对话框。
  • 从“所有文档”对话框关闭文档后，标题栏未更新。
  • 通过 Shift+F1 打开时，Readme.html 将不再被添加到所有文档列表中。
  • 从最近文档对话框中移除文档现在也会关闭其活动选项卡。
  • 移除文档后，搜索筛选器现在会被保留。

导航

  • 页面导航在某些情况下朗读错误的行文本。
  • 转到行、转到页和转到百分比在大型文档中将光标置于错误位置。
  • 在大型文档中，查找和查找下一个未遵守已加载的文档窗口。

书签

  • 书签/笔记声音现在应当仅在您导航到包含它们的单词时才正确播放。

可读性

  • 应用自动换行会将您弹到文档开头。

Web 视图

  • Web 视图对话框不可调整大小，并且初始弹出尺寸非常小。
  • 图片现在应能在嵌入式 Web 视图中正确显示。

更新器

  • 更新器现在能正确显示发行说明中 Markdown 代码标签的内容。

DAISY 图书

  • DAISY 图书在状态栏中显示不正确的信息。
  • 加载带有虚假编码声明的 DAISY 图书。

RTF 文档

  • 解析包含非拉丁字符的 RTF 文档。
  • RTF \pict 组，嵌入式图片数据不再泄漏到文档文本中。

Mobi/AZW3 图书

  • Mobi 图书中的 Filepos 锚点会拆分 HTML 标签并在图书文本中产生垃圾内容。
  • 旧版 Mobi 图书中的链接。
  • 大幅改进了 AZW3 解析。

Word 文档

  • 具有区域设置特定样式名称的 Word 文档无法正确渲染其标题。

HTML/XHTML 文档

  • dl、dt 和 dd 元素在 XHTML 文档中不产生换行符。

PDF 文档

  • 对于标记错误的 PDF，Paperback 现在会回退到纯文本提取。
  • 标题和/或书签中包含控制字符的 PDF 文档在打开时不再导致 Paperback 崩溃。

  • 添加了对加密 Microsoft Office 文档的支持。目前支持旧版 Word、新版 Word 和新版 PowerPoint，旧版 PowerPoint 计划在未来支持。
  • 添加了对旧版 Microsoft Word 文档（*.doc）的支持！
  • 添加了对旧版 PowerPoint 演示文稿（*.ppt）的支持！
  • 添加了对 mobi 和 AZW3 图书的支持！
