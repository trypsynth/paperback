Вступ

Paperback — це легка, швидка та доступна програма для читання електронних книг, документів та аудіокниг, призначена для всіх: від звичайних читачів до досвідчених користувачів. Вона розроблена з урахуванням доступності для зчитувачів екрана, високої швидкості роботи та відсутності зайвого функціоналу.

Системні вимоги

Paperback працює на Windows 10/11, усіх сучасних версіях macOS для архітектури ARM, Linux, iOS 17 і новіших, а також Android 7 і новіших. Застосунки для iOS та Android доступні в App Store та Google Play.

Можливості

  • Повністю автономна, для початку читання не потребує встановлення жодного додаткового програмного забезпечення на комп’ютер.
  • Неймовірно швидка навіть на застарілому обладнанні.
  • Простий інтерфейс із вкладками, що дозволяє відкривати поруч стільки документів, скільки вам потрібно.
  • Зберігає точну позицію читання в кожному відкритому документі.
  • За бажанням запам’ятовує, які документи були відкриті на момент закриття програми, і відновлює їх під час наступного запуску.
  • Містить функції навігації, схожі на режим огляду вебсторінок у багатьох зчитувачах екрана, для швидкої та зручної навігації по документах.
  • Містить функціональне діалогове вікно пошуку, яке включає такі функції, як історія пошуку та підтримка регулярних виразів.
  • Може працювати повністю портативно або встановлюватися з автоматичним налаштуванням асоціацій файлів.
  • Підтримує величезну кількість поширених форматів файлів.
  • Відтворює аудіокниги з регульованою швидкістю та закладками, що запам’ятовують точний час.
  • Розпізнає відскановані сторінки PDF за допомогою вбудованого в Windows та macOS розпізнавання тексту (OCR).
  • Закладки та нотатки, завдяки яким ви можете позначити потрібне місце й повернутися до нього.
  • Можливість змінити будь-яку комбінацію клавіш.
  • Містить pb — утиліту командного рядка, яка конвертує будь-який підтримуваний документ у HTML, Markdown або звичайний текст.

Сумісність зі зчитувачами екрана

Paperback добре працює з усіма основними скрінрідерами. Проте існує одна відома проблема для користувачів JAWS.

JAWS і дисплеї Брайля

Якщо ви використовуєте JAWS разом із брайлівським дисплеєм, ви можете помітити, що довгі абзаци обрізаються під час прокрутки вперед за допомогою клавіш навігації вашого дисплея. Це також стосується команди «Прочитати поточний абзац». Це помилка в обробці JAWS текстового елемента RICHEDIT50W, а не в самій програмі Paperback, і знадобилося чимало часу, щоб знайти виправлення, зважаючи на те, з яким ентузіазмом Vispero реагує на проблеми з програмним забезпеченням з відкритим кодом.

Обхідне рішення, яке після кількох місяців очікування з’явилося в дискусійній групі JAWS, полягає в тому, щоб відредагувати paperback.jcf і встановити параметр “Braille Presentation and Panning” у значення “Always use DOM if available”. Також потрібно ввімкнути “Pan Text by Paragraph”, інакше дисплей залишатиметься на активному абзаці замість переходу вперед. За наявності обох цих налаштувань прокрутка має працювати належним чином.

JAWS і повідомлення Paperback

Додаток Paperback надсилає сповіщення доступності типу «Немає сторінок» або «У цьому документі немає аудіо». Саме це дозволяє скрінрідеру озвучувати їх поверх поточного мовлення. JAWS реагує на такі повідомлення лише тоді, коли для програми ввімкнено опцію «Увімкнути події сповіщень доступності» (в деяких системах вона початково вимкнена).

Якщо під час натискання комбінації клавіш, яка має виводити інформацію, JAWS нічого не озвучує, то перебуваючи у програмі Paperback відкрийте Центр налаштувань (Insert+6). Знайдіть у пошуку слово «сповіщення» та позначте прапорцем пункт «Увімкнути події сповіщень доступності». Це запише налаштування у файл paperback.jcf, тому воно застосовуватиметься лише до Paperback.

Підтримувані наразі типи файлів

Paperback підтримує такі формати й розширення:

  • Архіви коміксів (.cbz)
  • Файли довідки CHM (.chm)
  • Книги DAISY (.opf, .zip)
  • Книги EPUB (.epub)
  • Електронні книги FB2 (.fb2)
  • Документи HTML (.htm, .html, .xhtml)
  • Сторінки довідки, як у форматі man, так і у форматі BSD mdoc (від .1 до .9, .man, .roff, а також відповідні файли у форматі gzip)
  • Документи Markdown (.md, .markdown, .mdx, .mdown, .mdwn, .mkd, .mkdn, .mkdown, .ronn)
  • Документи Microsoft Word (.docx, .docm, .doc)
  • Аудіокниги M4B (.m4b)
  • Книги MOBI/Kindle (.mobi, .azw, .azw3)
  • Аудіокниги MP3 (.mp3)
  • Презентації OpenDocument (.odp, .fodp)
  • Текстові файли OpenDocument (.odt, .fodt)
  • Документи PDF (.pdf)
  • Презентації PowerPoint (.pptx, .pptm, .ppt)
  • Документи reStructuredText (.rst, .rest)
  • Документи RTF (.rtf)
  • Документи Windows Write (.wri)
  • Файли WinHelp (.hlp)
  • Звичайний текст і файли журналів (.txt, .log)

Комбінації клавіш

Paperback розроблено для роботи переважно за допомогою клавіатури. Ось перелік поточних комбінацій клавіш.

Наведені нижче комбінації клавіш призначені для Windows. Відмінності для macOS зазначено в дужках — переважно тому, що Ctrl+G, Ctrl+W та Alt+Left/Right уже закріплені за іншими системними або призначеними для застосунків правилами на цій платформі.

Меню «Файл»

  • Ctrl+O: Відкрити документ.
  • Ctrl+F4 (macOS: Cmd+W): Закрити поточний документ.
  • Ctrl+Shift+F4 (macOS: Cmd+Shift+W): Закрити всі відкриті документи.
  • Ctrl+Shift+T: Заново відкрити останній закритий документ.
  • Ctrl+R: Відкрити діалог «Усі документи» (з підменю «Останні документи»).
  • Ctrl+Q: Вийти (тільки для Windows; у macOS це знаходиться в меню застосунку).

Меню «Перейти»

  • Ctrl+F: Показати діалог пошуку.
  • F3 (macOS: Cmd+G): Знайти далі.
  • Shift+F3 (macOS: Cmd+Shift+G): Знайти попереднє.
  • Ctrl+G (macOS: Cmd+L): Перейти до рядка.
  • Ctrl+Shift+G (macOS: Cmd+Shift+L): Перейти до відсотка.
  • Ctrl+P: Перейти до сторінки (якщо підтримується поточним документом).
  • =: Озвучити поточний відсоток прочитаного та номер сторінки, наприклад: «15%, сторінка 30». У документах без нумерації сторінок номер сторінки не вказується.
  • Alt+Left (macOS: Cmd+[): Перейти назад в історії навігації.
  • Alt+Right (macOS: Cmd+]): Перейти вперед в історії навігації.
  • [: Попередній розділ.
  • ]: Наступний розділ.
  • Shift+H: Попередній заголовок.
  • H: Наступний заголовок.
  • Від Shift+1 до Shift+6: Попередній заголовок рівня 1–6.
  • 1–6: Наступний заголовок рівня 1–6.
  • Shift+P: Попередня сторінка.
  • P: Наступна сторінка.
  • Shift+B: Попередня закладка.
  • B: Наступна закладка.
  • /: Встановити тимчасову закладку.
  • \: Перейти до тимчасової закладки.
  • Shift+N: Попередня нотатка.
  • N: Наступна нотатка.
  • Ctrl+B: Перейти до всіх закладок і нотаток.
  • Ctrl+Alt+B: Перейти лише до закладок.
  • Ctrl+Alt+M: Перейти лише до нотаток.
  • Ctrl+Shift+W (macOS: RawCtrl+Shift+W, тобто фізична клавіша Control замість Cmd): Переглянути текст нотатки в поточній позиції.
  • Shift+K: Попереднє посилання.
  • K: Наступне посилання.
  • Shift+G: Попереднє зображення.
  • G: Наступне зображення.
  • Shift+F: Попередній малюнок.
  • F: Наступний малюнок.
  • Shift+T: Попередня таблиця.
  • T: Наступна таблиця.
  • Shift+M: Попередній математичний вираз.
  • M: Наступний математичний вираз.
  • Shift+S: Попередній роздільник.
  • S: Наступний роздільник.
  • Shift+L: Попередній список.
  • L: Наступний список.
  • Shift+I: Попередній елемент списку.
  • I: Наступний елемент списку.
  • Shift+,: Перейти до початку поточного контейнера (списку чи таблиці).
  • ,: Перейти за межі кінця поточного контейнера (списку чи таблиці).

Меню «Інструменти»

  • Ctrl+W (macOS: RawCtrl+W, тобто фізична клавіша Control замість Cmd): Показати кількість слів у поточному документі.
  • Ctrl+I: Показати відомості про документ.
  • Ctrl+T: Показати зміст.
  • F7: Показати список елементів.
  • Ctrl+Shift+C: Відкрити папку, в якій знаходиться файл.
  • Ctrl+Shift+V: Відкрити поточний вміст у вебпереглядачі.
  • Ctrl+U: Переглянути джерело документа в новій вкладці.
  • Ctrl+Shift+E: Експортувати дані документа (.paperback).
  • Ctrl+Shift+I: Імпортувати дані документа (.paperback).
  • Ctrl+E: Експортувати поточний документ у звичайний текст.
  • Ctrl+Shift+B: Додати або видалити закладку у місці поточного виділення/позиції курсора.
  • Ctrl+Shift+N: Додати або редагувати нотатку до закладки у місці поточного виділення/позиції курсора.
  • Ctrl+Alt+W: Увімкнути/вимкнути перенесення слів.
  • Ctrl+Space (macOS: RawCtrl+Space, тобто фізична клавіша Control замість Cmd, оскільки Cmd+Space відкриває Spotlight): Відтворити/призупинити аудіо.
  • ': Перемотати вперед.
  • ;: Перемотати назад.
  • Shift+': Збільшити крок перемотування аудіо.
  • Shift+;: Зменшити крок перемотування аудіо.
  • Ctrl+Shift+.: Прискорити відтворення аудіо.
  • Ctrl+Shift+,: Уповільнити відтворення аудіо.
  • F11 (macOS: RawCtrl+Ctrl+F, тобто Control+Command+F): Перемикання повноекранного режиму.
  • Ctrl+,: Відкрити налаштування (macOS: у меню застосунку).
  • Ctrl+Shift+S: Увімкнути/вимкнути таймер сну.
  • Ctrl+Shift+O: Розпізнати діапазон відсканованих сторінок PDF за допомогою OCR.
  • Alt+F9 (macOS: Cmd+F9): Встановити початкову позицію виділення, щоб увесь текст від неї до поточної позиції можна було скопіювати одразу.
  • Alt+F10 (macOS: Cmd+F10): Скопіювати все від позначеного початку виділення до поточної позиції.
  • Alt+Shift+F9 (macOS: Cmd+Shift+F9): Перейти назад до позначеного початку виділення, залишивши позначку на місці.

Меню «Довідка»

  • Ctrl+F1: Показати діалог «Про програму».
  • F1: Переглянути довідку в типовому браузері.
  • Shift+F1: Переглянути довідку в Paperback.
  • Ctrl+Shift+U: Перевірити наявність оновлень.
  • Ctrl+D: Відкрити сторінку пожертв у типовому браузері.

Додаткові клавіші перегляду документа

  • Delete / Numpad Delete на панелі вкладок: Закрити вибрану вкладку документа.
  • Enter або Space у тексті документа: Перейти за посиланням або відкрити режим перегляду таблиці чи формули під курсором.
  • Enter на відсканованій сторінці PDF: Розпізнати сторінку за допомогою OCR.
  • Shift+F10 або клавіша Application у тексті документа: Відкрити контекстне меню.

iOS та Android

Застосунки для iOS та Android використовують той самий рушій читання, що й версія для комп’ютера, тому вони відкривають ті самі формати й так само запам’ятовують вашу позицію читання. Вони створені для використання з VoiceOver на iOS та TalkBack на Android.

Відкриття документів

  • Натисніть кнопку «Відкрити книгу» або відкрийте документ у додатку «Файли» чи іншому додатку та виберіть «Paperback».
  • В Android ви натомість можете увімкнути в налаштуваннях вбудований у додаток файловий менеджер. Для його роботи потрібен дозвіл «Доступ до всіх файлів», і він відкриває великі файли миттєво замість того, щоб спочатку копіювати їх.
  • Натисніть і утримуйте кнопку «Відкрити книгу», щоб імпортувати або експортувати дані документа (.paperback) — ті самі файли, які використовує десктопний застосунок.

Читання та прослуховування

У кожному застосунку є два способи читання документа. У режимі тексту ви читаєте текст за допомогою свого скрінрідера. У режимі читання вголос Paperback озвучує вам текст голосом, вибраним у Налаштуваннях, і продовжує працювати у фоновому режимі та з екрана блокування. Перемикайтеся між режимами за допомогою меню «Інші параметри».

Аудіокниги, такі як книги DAISY, M4B та MP3, натомість відтворюють власний запис.

Панель читання

На панелі внизу екрана зліва направо розташовані:

  • Повзунок «Тип навігації», наприклад, абзац, заголовок, сторінка або посилання. Для зміни типу проведіть на ньому пальцем вгору або вниз.
  • Кнопки «Назад», «Відтворити» і «Далі». Кнопки «Назад» і «Далі» здійснюють перехід за вибраним типом навігації.
  • Повзунок «Темп мовлення». Для зміни швидкості читання Paperback проведіть на ньому вгору або вниз.

Ви також можете провести вгору або вниз на кнопці «Відтворити», щоб гортати текст за вибраним типом навігації, не тягнучись до кнопок «Назад» і «Далі». Якщо ви користуєтеся лише цим жестом, налаштування «Приховувати кнопки «Назад» і «Далі»» прибере їх, щоб вони не заважали навігації скрінрідера. Налаштування «Проведення вгору: перехід далі» визначає напрямок дії цього жесту.

Інші параметри

У меню «Інші параметри» міститься решта всіх функцій. Деякі пункти працюють дещо по-різному на кожній платформі.

  • Перейти в режим читання вголос або Перейти в режим тексту: перемикає між режимами, описаними вище. У режимі тексту пункт «Читати вголос» запускає та призупиняє читання вголос без виходу з цього режиму.
  • Зміст: розділи книги; відкривається на тому, який ви зараз читаєте. Виберіть розділ, щоб перейти безпосередньо до нього. Елементи, що містять підрозділи, можна розгортати та згортати за допомогою стандартних дій скрінрідера.
  • Список елементів: список заголовків або посилань документа. Перемикайтеся між ними за допомогою вибору типу на iOS або вкладок на Android, а потім виберіть елемент, щоб перейти до нього.
  • Пошук: введіть текст для пошуку або виберіть попередній запит з історії пошуку, а також за потреби ввімкніть урахування регістру, пошук лише цілих слів чи використання регулярних виразів. Кнопки «Знайти назад» та «Знайти далі» здійснюють перехід до збігу й озвучують його розташування, а вікно пошуку залишається відкритим для продовження роботи. У режимі читання вголос пошук також з’являється як тип навігації на панелі мовлення, що дозволяє переходити між збігами безпосередньо звідти.
  • Перейти: перехід до певного рядка, сторінки або відсотка в документі. Виберіть потрібний варіант за допомогою засобу вибору режиму.
  • Останні документи: кожен відкритий вами документ, позначений як «Наразі відкритий», «Закритий» або «Файл відсутній». Для кожного з них доступні дві дії скрінрідера: Вилучити видаляє його зі списку, а Знайти дозволяє знайти документ, файл якого було переміщено. Очистити останні документи очищає список, не видаляючи самі документи.
  • Кількість слів: кількість слів у документі.
  • Відомості про документ: назва, автор, ім’я файлу, а на iOS — також кількість рядків і символів.
  • Експорт: зберігає документ у форматі звичайного тексту, HTML або Markdown.
  • Таймер сну: зупиняє читання через 5, 10, 15, 30, 45 чи 60 хвилин або через указаний вами час. Відкрийте його знову під час роботи, щоб дізнатися, скільки залишилося часу, або щоб скасувати його.
  • Довідка: відкриває цей файл readme.
  • Налаштування:
    • Мовлення: голос, темп і тон, кнопка «Відтворити зразок» для прослуховування, а також пауза між абзацами. На Android ви також можете вибрати синтезатор мовлення. На iOS у цьому ж розділі доступний словник вимови — правила, які змінюють спосіб озвучення слів для всіх або лише для деяких голосів.
    • Читабельність: розмір тексту, міжрядковий інтервал, інтервал між абзацами, вирівнювання та висококонтрастний текст. iOS також має світлий і темний варіанти оформлення.
    • Поведінка: чи відкривати документи під час запуску додатка, напрямок переходу за проведенням на кнопці «Відтворити» та чи приховувати кнопки «Назад» і «Далі». На Android у цьому ж розділі розташований вбудований файловий менеджер.

Клавіатури та гарнітури

При використанні клавіатури на iOS всі настільні комбінації клавіш для відкриття книг, останніх документів, пошуку, переходу, змісту, підрахунку слів, відомостей про документ, експорту та таймера сну працюють так само, використовуючи Cmd замість Ctrl. Також працюють однолітерні клавіші для переходу за заголовком, сторінкою, посиланням тощо, а клавіша Пробіл — для відтворення та призупинення. На iOS натискання окремих літерних клавіш передається в Paperback лише тоді, коли у VoiceOver вимкнено швидку навігацію за буквами.

На Android кнопка гарнітури керує відтворенням і паузою одним натисканням, переходить уперед подвійним і повертає назад потрійним.

1.0 — це перший випуск на всіх п’яти платформах: Windows, macOS, Linux, iOS та Android, причому застосунки для iOS та Android доступні в App Store та Google Play.

Додано

Загальне

  • Підтримка Linux у форматі AppImage або архіву tar.gz з інтеграцією в систему для відкриття документів безпосередньо з файлового менеджера.
  • Позначення початку виділення за допомогою Alt+F9, копіювання всього від позначки до поточної позиції за допомогою Alt+F10 та повернення до позначки за допомогою Alt+Shift+F9, що зручно для копіювання великих фрагментів тексту без виділення стрілками з Shift. Усі три дії доступні в меню «Інструменти» > «Виділити та скопіювати».
  • Тепер комбінація клавіш = озвучує не лише відсоток, а й номер сторінки, наприклад: «15 %, сторінка 30», а для документів без нумерації сторінок все залишається як і раніше.
  • У вікні «Про програму» тепер відображається інформація про ліцензію Paperback та імена всіх перекладачів.

Нові формати

  • Архіви коміксів (.cbz).
  • Аудіокниги M4B із розбиттям на розділи.
  • Сторінки довідки, як man, так і BSD mdoc, стиснені в gzip або без стиснення.
  • Аудіокниги MP3 із розбиттям на розділи, якщо вони є у файлі.
  • Документи reStructuredText.
  • Файли Windows Write (.wri).
  • Файли WinHelp (.hlp).
  • Документи Word 6 та Word 95.

OCR

  • Відскановані сторінки PDF тепер можна розпізнавати за допомогою вбудованого в Windows та macOS розпізнавання тексту (OCR). Натисніть Enter на відсканованій сторінці, щоб розпізнати її, або скористайтеся пакетним розпізнаванням OCR (Ctrl+Shift+O) для діапазону сторінок.

Навігація

  • Математичні вирази MathML в EPUB та HTML відображаються як AsciiMath за допомогою MathCAT. Використовуйте M або Shift+M для навігації по математичних виразах, а потім Enter або Space, щоб відкрити оригінальний MathML у режимі перегляду виразів.
  • Кнопка «Знайти все» в діалоговому вікні пошуку, яка відображає список усіх рядків зі збігами для швидкого переходу до потрібного.
  • Фільтрація за таблицями, списками та сторінками у списку елементів (F7).
  • Команди «Перейти до рядка», «Перейти до сторінки» та «Перейти до відсотка» тепер приймають +n та -n для відносного переміщення від поточної позиції.
  • Книги у форматах EPUB, MOBI та CHM, які не містять власних заголовків, тепер отримують навігацію за заголовками на основі їхнього змісту.
  • Книги у форматі KF8 (AZW3) тепер підтримують навігацію по розділах.
  • На сторінках у форматі EPUB, які містять лише зображення, тепер відображається відповідний рядок, тож ви можете перейти безпосередньо до них, а не пропускати їх.

Аудіокниги

  • Керування швидкістю відтворення: від половинної до потрійної швидкості. Використовуйте Ctrl+Shift+. та Ctrl+Shift+, або меню «Інструменти».
  • Закладки та нотатки в аудіокнигах тепер запам’ятовують точний час, на який ви їх встановили.
  • Перехід до наступної та попередньої позиції (Alt+Left та Alt+Right) тепер працює в аудіокнигах.
  • Прогрес в аудіокнигах тепер вимірюється за часом запису, тому функція «Перехід до відсотка» та рядок стану точно відображають, наскільки далеко ви просунулися.

Останні документи

  • Пункт «Очистити останні документи» в підменю останніх документів.

Документи PDF

  • Параметр, що дозволяє зберігати кожен рядок PDF-файлу окремо, а не об’єднувати їх в абзаци.
  • Зображення та малюнки у файлах PDF тепер озвучуються.
  • Файли PDF зі структурою читання, де зображення не розмічені тегами, тепер озвучують ці зображення замість повного вилучення їх із книги.

Вебперегляд

  • Тепер у вебперегляді можна відкривати будь-які документи, а не лише файли у форматах EPUB, HTML та Markdown.

Читабельність

  • Заголовки тепер відображаються розміром, що відповідає їхньому рівню, а зображення та таблиці відокремлені від навколишнього тексту.

pb

  • Команда pb --list-formats показує список усіх форматів, які може читати pb.
  • pb тепер повідомляє, який саме файл не вдалося прочитати та чому.

Виправлено

Загальне

  • Книга, яку знову відкрили під час запуску, тепер читається відразу, а не залишається неактивною, доки її не закриють і не відкриють знову.
  • Документи, файли яких було видалено або переміщено з пристрою, тепер можна вилучити зі списку «Усі документи» (раніше вони залишалися в списку попри підтвердження дії).
  • Виправлено збій програми під час закриття Paperback.
  • Закриття Paperback тепер одразу приховує вікно замість того, щоб залишати його на екрані під час збереження.
  • Великі книги з мінімальним форматуванням тепер відкриваються приблизно вдвічі швидше.
  • Повідомлення, вибрані з меню, наприклад «У цьому документі немає аудіо», більше не обрізаються скрінрідером до того, як ви їх почуєте.
  • Відкриття документа більше не залишає дію «Відкрити останній закритий файл» активною, коли немає чого відкривати.
  • Програма Paperback більше не намагається повторно завантажити документи зі списку останніх, які зникли, і обмежує кількість документів, що зберігаються у цьому списку.
  • Старий файл налаштувань INI тепер видаляється після перенесення у новий формат.
  • Заголовки діалогових вікон вибору шрифту й кольору, а також меню «Експортувати як» у в’єтнамській локалізації тепер перекладено.
  • Тепер під час оновлення вікно, яке було перезапущено, виводиться на передній план, а не залишається позаду всіх інших вікон у режимі Alt+Tab.
  • Перенесення слів тепер застосовується миттєво у великих документах без повного перезавантаження всього вмісту.

Навігація

  • Alt+Left тепер повертає туди, звідки ви перейшли, а не на давнішу позицію.
  • Звуки закладок тепер відтворюються лише під час переміщення через закладку, а не під час переходу на рядок, де вона розташована.
  • Після закриття змісту, списку елементів та діалогів переходу, ви тепер одразу переходите до рядка, на якому перебуваєте, а не мусите чекати, поки скрінрідер знову зачитає вміст вікна.
  • Команди «Перейти до рядка», «Перейти до сторінки» та «Перейти до відсотка» тепер відхиляють номери за межами документа замість мовчазного переходу в інше місце.
  • NVDA більше не обрізає озвучування, коли документ не містить сторінок.
  • Натискання OK у змісті без переміщення курсора тепер переходить до вже вибраного елемента.
  • Зміст, список елементів та список закладок більше не зависають і не гальмують у книгах із тисячами записів.
  • Стрілки «Вгору» та «Вниз» тепер запам’ятовують свій стовпець для кожного документа окремо, а не переносять його при переході між вкладками.

Аудіокниги

  • Відтворення аудіо на macOS тепер використовує Control+Space, оскільки Command+Space закріплено за Spotlight.

Документи PDF

  • Виправлено помилку, через яку PDF-файли, експортовані з Apple Pages, відкривалися як звичайний текст без заголовків та списків, які були вказані під час їх створення.
  • Виправлено розбиття абзаців і заголовків у PDF-файлах на кожному рядку, а також розбиття слів на пробілах.
  • Виправлено злиття нумерованих заголовків PDF в один заголовок.
  • Виправлено помилку, через яку PDF-файли, структура яких не містила тексту, відкривалися порожніми.
  • Верхні та нижні колонтитули більше не зачитуються на кожній сторінці PDF-файлів без тегів.
  • Файли PDF, що позначають колонтитули як звичайний текст, більше не повторюють назву та номер сторінки між двома абзацами на кожній сторінці.
  • Документи PDF тепер показують справжню назву замість імені файлу.
  • Рядки, набрані моноширинним шрифтом (наприклад, код), більше не об’єднуються в абзаци.

Книги MOBI/AZW3

  • У великих книгах MOBI більше не вичерпується пам’ять і вони більше не обрізаються після 20 МБ.
  • Книги MOBI та AZW3 тепер відкриваються набагато швидше.
  • Виправлено втрату списку розділів у книгах MOBI.
  • Виправлено спотворення тексту на межі переходів між записами у книгах MOBI.

Вебперегляд

  • Вебперегляд більше не завантажує всю величезну книгу одночасно.
  • Вебперегляд тепер показує документи повністю, коли читалці доступний увесь документ, а не лише його частина.

Інші формати

  • Книги FictionBook (.fb2), збережені в кодуванні windows-1251 (а це більшість із них), тепер відкриваються замість збою читання.
  • Книги FictionBook, що використовують незадекларований простір імен або HTML-сутності, тепер відкриваються замість відхилення як пошкоджені.
  • Книги в застарілих кодуваннях тепер відкриваються набагато швидше.
  • Виправлено відкриття деяких китайських текстових файлів у вигляді нечитабельного тексту.
  • Файли OpenDocument, захищені паролем, тепер вимагають введення пароля, а не відображаються як пошкоджені.
  • Старі файли PowerPoint, захищені паролем, тепер відкриваються, а текст на старих слайдах PowerPoint більше не втрачається.
  • Текстові файли, збережені з розширенням .rtf, тепер відкриваються як текст замість завершення з помилкою.
  • Керуючі слова RTF більше не відображаються як текст.

  • Виправлено помилку, коли файли EPUB із випадковим блоком ZIP64 відмовлялися відкриватися з повідомленням “Invalid local file header”.
  • Виправлено помилку, коли довгі документи поверталися на початок під час безперервного читання скрінрідером.
  • Посилання у WebView тепер переходять безпосередньо до розділу, на який вони вказують, замість збою з помилкою “File not found”.

  • Windows тепер завжди відображатиме “Paperback” у меню «Відкрити за допомогою» замість повного гасла програми.
  • «Кількість слів» та «Відомості про документ» тепер показують, скільки файлів містить аудіокнига та яка її загальна тривалість.

Версія 0.9.0

Додано

Загальне

  • Утиліта командного рядка pb для швидкого конвертування будь-якого з підтримуваних Paperback форматів у HTML, Markdown або звичайний текст.
  • Опція автоматичного перезавантаження документів, якщо вони були змінені іншими програмами на диску.
  • Опція «Переглянути джерело» для відкриття вихідного тексту документа на новій вкладці, що корисно, наприклад, для редагування Markdown.
  • Текст документа тепер розбивається на сторінки, завдяки чому книги на десятки мільйонів слів завантажуються всього за кілька секунд. Будь ласка, повідомляйте про будь-які виявлені збої.

Підтримка платформ

  • Підтримка Windows для ARM64!
  • Нативна підтримка macOS!
  • Перемикач повноекранного режиму.

Діалогове вікно «Усі документи»

  • Кнопка пошуку для визначення розташування відсутніх книг, у яких змінився шлях.
  • Фільтр стану та рядок стану, що дозволяють фільтрувати за станом документа й бачити, скільки документів відображено та вибрано.
  • Комбінація клавіш Ctrl+Shift+A для зняття виділення з усіх документів.

Параметри та зручність читання

  • Вкладка зручності читання з такими параметрами:
    • Перенесення слів (перенесено з розділу «Загальні»);
    • Відображення таблиць у тексті (нове в цьому випуску, див. нижче);
    • Шрифт;
    • Колір фону;
    • Міжрядковий інтервал;
    • Інтервал між абзацами;
    • Міжлітерний інтервал;
    • Вирівнювання тексту.
  • Пункт меню перенесення слів та відповідна гаряча клавіша.
  • Перемикач для налаштування способу відображення таблиць і стандартизація показу таблиць для всіх документів.

Навігація

  • Підтримка навігації контейнерами.
  • Опція автоматичного переміщення курсора на початок рядка під час переходу між рядками, подібно до режиму перегляду в скрінрідерах.
  • Комбінація клавіш «=» дозволяє озвучити поточний відсоток прочитання документа.

Закладки

  • Тимчасові закладки: можна мати по одній на документ, і вони зберігаються. Використовуйте скісну риску для встановлення та зворотну скісну риску для переходу до неї.

Кількість слів

  • Орієнтовний час читання в діалоговому вікні підрахунку слів, а також можливість указати власну швидкість читання, щоб цей показник був дійсно корисним.
  • Якщо під час відкриття діалогового вікна підрахунку слів є виділений фрагмент, тепер відображається кількість виділених слів.

Комбінації клавіш

  • Можливість налаштувати будь-яку комбінацію клавіш у застосунку через просте діалогове вікно.
  • Настроювана комбінація клавіш для відновлення Paperback із системного трею.

Мови

  • Нідерландська, фінська та польська.

Експорт

Засіб оновлення

  • Спроби функції «Відкрити заново останній закритий» відкрити вбудований файл readme.
  • Відсутність належного фокуса на вибраній вкладці після перезапуску Paperback.
  • Роботу Paperback із файлами на мережевих дисках Windows: дія «Показати файл у папці» тепер коректно фокусує файл на мережевому сховищі, а шляхи більше не містять некоректних символів.
  • Файли .paperback більше не завантажуватимуться примусово під час відновлення документа; натомість запитуватиметься підтвердження у разі виявлення такого файлу.
  • Команда «Відкрити папку з файлом» тепер фокусує вибраний файл у Провіднику.
  • Відкриття readme тепер враховує вибрану вами мову.
  • Інтерфейс користувача Paperback тепер коректно масштабується на екранах із високою роздільною здатністю (high-DPI).
  • Меню тепер належним чином оновлюється, а фокус переходить до текстового поля під час відкриття довідки всередині Paperback.
  • Перехід на значно безпечніший метод IPC у Windows.
  • Назва активного документа тепер озвучується під час перемикання між вкладками.
  • Зменшено споживання пам’яті для великих документів завдяки скороченню вдвічі розміру внутрішніх таблиць посимвольних індексів.
